# KeepAny

数据由用户掌握的开源个人资产工作台。统一管理项目、账号、订阅、实物及其关联与维护事项。

## 当前状态

**已完成产品/架构规划与UI参考归档；尚未创建正式应用、实现云同步或部署服务。**

- 首期语言：简体中文 `zh-CN`、英语 `en`。
- 核心：本地可用、不要求注册、可完整导出；官方云同步和AI服务可选。
- 密码：首期只引用专业密码库条目，不保存密码、恢复码或主密码。
- UI参考为中文单文件交互原型，不代表生产安全、持久化或真实后端已完成。

## 目录约定

当前只建立文档与设计资料。正式开发按文档创建 `apps/web`、`apps/sync-server`、`apps/worker`、`packages/*`，不把演示HTML当应用入口。

商业官网、会员与运营后台计划放在同级 `../KeepAny-Cloud`，独立仓库，不置于本仓库。当前未下载或复制 ShipAny 模板。

开源核心推荐采用 AGPL-3.0-only；最终发布前核查所有实际复用文件及许可证兼容性。当前没有导入第三方业务源码，也没有把规划文档宣称为已经许可完整产品。不得把 ShipAny 源码、密钥、生产数据或不明来源素材加入本仓库。
