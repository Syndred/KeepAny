# 手机迁入与备份草图

建议 A，待用户确认。A用完整核对页展示范围；B压缩清单并可展开。两个方案均保留独立密码库、恢复目标与原资料保留说明。

三屏分别是首次迁入、恢复核对、日常备份。可演示选择合成备份、密码错误、核对、恢复进度与结果，以及恢复中断／继续／保留当前、备份失败、生成文件与选择保存位置。

使用本目录 `index.html`。通过根目录静态服务访问时路径为 `.planning/sketches/002-mobile-restore/index.html`。示例备份密码 `demo-backup-2026`；它只用于内存中的错误／成功状态演示，不解密任何实际文件。

控制栏的“失败”“恢复中断”用于审阅状态；设备框内只有产品文案。不会触发真实导入、导出、分享、网络或密码操作。草图不能作为 SQLite 或真实备份恢复验收。

审阅重点：完整恢复范围是否易读；原资料与密码库状态是否清楚；中断后是否知道下一步；“文件已生成”和“保存位置已打开”是否准确区分。
