桌面同时预览三屏，窄屏通过“页面”切换；支持中英文、360／390／430宽度、空资料、间距标注。可操作底栏、分类、搜索、账号详情、关系图、编辑、新建、待办勾选、密码库锁定／示例解锁和收录核对。

浏览器打开本目录 `index.html`，或从仓库根运行 `python3 -m http.server 4196 --bind 127.0.0.1` 后访问 `http://127.0.0.1:4196/.planning/sketches/001-mobile-everyday/index.html`。预览使用专属端口，不能把4196当作已有资料的4180入口。

所有资料均为示例，所有修改只存在本页内存。没有数据库、网络、AI、系统文件选择或剪贴板写入；复制、保存、解锁是排版／交互演示。刷新重置，不输入真实密码或备份。
