# AI 功能与验收合同（2026-10-01）

## 用户确认范围

AI 支持导入分析、自然语言查找、创建与修改订阅／待办提醒、资料整理建议；主流模型与自定义服务共用配置。通知本轮仅应用内及浏览器系统通知，关页后台推送后续实现。真实验收使用用户授权的 DeepSeek API、合成资料和明确要求整理的去除密码后的账号清单，禁止以模拟请求冒充真实模型通过。

## 复用与数据边界

- 模型协议优先成熟 AI SDK；原生 OpenAI、Anthropic、Gemini 与 OpenAI 兼容提供方分开适配，供应商标签不代表每个模型已实测。来源、精确依赖版本、许可证另记。
- 配置保存服务／模型；明确选择「仅本次使用」的密钥只在内存。长期密钥可在设置页直接加密保存至本机 KDBX，也可选择已有条目；普通配置仅存条目引用和自动启用偏好。用户勾选解锁后自动启用并保存时，授权目标同时写入 KDBX 的受保护自定义字段；后续只有提供方／API地址精确匹配的所选条目可在解锁后恢复。旧无自动授权配置仍需手动启用。不写普通资产、日志、同步或请求正文；锁库、所选密钥变更／删除／授权撤销和配置变化取消旧请求，无关条目修改不使同一密钥失效。
- AI 导入生成有来源的候选，不直接落资产／账单；候选支持逐项编辑和批量确认。用户审核确认后，明确的邮箱／完整手机号标识可创建登录账号依赖，已有确认清单可补齐；相关名称 relatedName 仍只是建议，不按名字猜关系。继续复用 FileStore 审核、RxDB 唯一资产源、稳定 ID、重复检测和实际加密备份。
- 明确提供的账号清单支持邮箱／手机号／用户名的来源核对及别名映射；用户名未知时保持为空，GitHub等登录方式保留在描述。文字／PDF提取文字检测到明示密码或密钥时先阻断发送；不承诺识别所有秘密或图片里的凭据。此导入授权不扩大问答所选字段。
- 自然语言检索先将问题转成有界查询计划，在本机查资产／关系／任务／财务；日期与金额由领域规则计算。仅问答中明确选择的有限资料发给模型，排除密码库、备注、联系方式、URL 凭据与密钥。所选资料保持kind/name/description/url/dueDate/amount/currency七字段，金额按币种主单位字符串发送；无账期字段不能推断每月费用。
- AI 操作只生成受限提醒计划；用户核对对象、日期时间、时区与重复规则后写入。目标不明确须选择，修改用当前记录 CAS；提醒由固定调度执行，不由模型循环判断。

## 密码清单全文 AI 识别追加范围（2026-10-04）

用户明确授权独立密码导入入口：复用已配置模型，将本次粘贴清单全文（含账号、密码和备注）发送到所选服务，支持官方云端和用户自部署的兼容接口，不要求下载 Ollama 或模型。按钮前显示模型、发送地址及敏感字段范围，不自动读取或发送已有密码库；主密码与连接 API Key 不进入请求正文。此范围仅覆盖用户主动选择的本次清单，不扩大普通收录／问答／MCP／资产同步的密码访问。

模型生成分组与原文引用，本机校验行范围、唯一子串、引用重叠、字段及缺项。完整行／多行保留原空白和换行，明确引用 JSON 字符串由本机解码，不接受虚构值。所有 AI 候选默认不勾选；未识别、AI 忽略和未知半行保留对应原文片段，密码及未确认文字默认遮罩。原文只读参考，旁边表单可新建待导入条目或明确补充本批目标；原文加入备注必须另点按钮，未改变已有目标不能提交。补填不调用模型，不自动猜字段或关联对象。确认后沿现有重复／冲突与修订比较流程写一份 KDBX 密文。关闭、锁库、配置变化及旧修订使异步结果失效；失败保留原文，不展示原始模型错误。原文与响应只在弹窗和调用内存，不持久到普通收录、日志、遥测或备份。

缺项但引用安全的AI条目保留为可编辑草稿，缺项提示附于该卡，不能勾选或写库；不再丢弃后重复显示为未知行。字段超长、NUL、虚构／重叠引用仍拒绝，并保留原行核对。完整条目独立预览与勾选，提交仅含已选有效条目，部分保存后保留其余草稿及编辑。审核来源记录本次实际模型／地址快照，普通配置变化不改写已生成结果的来源。共享服务标题由AI引用原文，不在本机猜测补配密码或跨节关联。

同密码的既有条目继续默认跳过。用户明确补充备注等字段后可选择具体更新对象，保存为同一条目的历史修订；密码相同不能通过「另存」制造重复，也不把补充内容静默丢弃。手工条目使用独立临时编号且不参与域名AI整理，整批秘密仍用于域名泄漏过滤。

审核条目以名称、账号和密码为核心，邮箱／App无需填写网址，URL和备注在可选信息中，有内容时展开。来源仅保留已验证字符范围／行范围，不复制秘密到持久状态。对应原文以生成该候选的清单快照为准，密码／备注／URL及未归属内容默认遮住，身份与秘密范围重叠时也遮住。逐片段显示为本机操作，无新请求。返回、收起、切换目标及部分入库保留其余候选、修改、勾选和未提交表单；仅剩片段也留在核对页。补充本批已保存条目明确更新同一KDBX对象并保存历史。已写入对象由核心实际按输入索引返回的ID回执关联，读取该对象最终值，不猜保存结果。高级手工映射只追加，失败块不消除原警告；不同原文快照存在未解决内容时保留映射、停止追加。成功重新识别明确替换本批未保存结果；关闭／锁库／刷新清空。

全文 AI 上限40,000字符／2,000行／200条，输出预算8,192 tokens；超大或截断结果提示重试／分批，不静默接受不完整JSON。复用 AI SDK、Zod、原解析器和统一React组件，无新依赖、无上游复制。自部署兼容接口支持本机HTTP回环地址或远端HTTPS，API Key可选择「服务无需密钥」；服务需允许浏览器CORS。

验收区分合成服务与真实供应商：点击前无请求，正文包含本次清单且不含全库／主密码／连接密钥，原密码字符／遗漏保留，确认刷新回读，失败／配置变化／锁库取消，中英手机／桌面。

## 历史密码库智能导入追加范围（2026-10-02，全文AI边界以上节为准）

用户授权新增独立密码库入口：明确字段的文字清单及 CSV／TSV／TXT 在本机识别；用户审核、处理重复／密码冲突后一次写入独立加密 KDBX，不使用普通资产或持久收录候选。密码、账号、备注、原文和原始标题均不进入模型。

可选网站名称整理复用既有模型连接，发送前展示准确的 `{id, host}` 清单，仅含临时编号和经过过滤的网站域名；排除网址路径、查询、片段、凭据、IP／本机地址、常见私有后缀及可疑域名。响应只能修改已发送条目的域名来源名称，不接受额外字段、陌生编号、重复编号或无来源的名称。关闭、锁库、配置／修订变化使请求失效；AI失败保留本机候选，不能自动写库。本功能不扩大普通AI导入或问答的密码库访问范围。

验收须分别证明本机识别保留密码字符、预览／AI不改密文、请求仅含预览字段、确认后刷新与实际 KDBX 恢复、重复跳过及更新历史、失败／取消／跨标签不覆盖。合成服务验证与真实 DeepSeek 调用分别记录，详见[密码库使用说明](密码库使用说明.md)及最新[项目交接](08-项目进度交接.md)。
