# AI 功能与验收合同（2026-10-01）

## 用户确认范围

AI 支持导入分析、自然语言查找、创建与修改订阅／待办提醒、资料整理建议；主流模型与自定义服务共用配置。通知本轮仅应用内及浏览器系统通知，关页后台推送后续实现。真实验收使用用户授权的 DeepSeek API 与合成资料，禁止以模拟请求冒充真实模型通过。

## 复用与数据边界

- 模型协议优先成熟 AI SDK；原生 OpenAI、Anthropic、Gemini 与 OpenAI 兼容提供方分开适配，供应商标签不代表每个模型已实测。来源、精确依赖版本、许可证另记。
- 配置保存服务／模型；会话密钥只在内存，长期凭据引用已有本机 KDBX，不写普通资产、日志、同步和请求正文。用户明确激活凭据，密码库锁定及配置变化取消在途请求。
- AI 导入生成有来源的候选，关联名称仅为建议，不自动创建关系，不直接落资产／账单；继续复用 FileStore 审核、逐项编辑确认、RxDB 唯一资产源、稳定 ID、重复检测和实际加密备份。
- 自然语言检索先将问题转成有界查询计划，在本机查资产／关系／任务／财务；日期与金额由领域规则计算。仅问答中明确选择的有限资料发给模型，排除密码库、备注、联系方式、URL 凭据与密钥。所选资料保持kind/name/description/url/dueDate/amount/currency七字段，金额按币种主单位字符串发送；无账期字段不能推断每月费用。
- AI 操作只生成受限提醒计划；用户核对对象、日期时间、时区与重复规则后写入。目标不明确须选择，修改用当前记录 CAS；提醒由固定调度执行，不由模型循环判断。

## 本轮完成门槛

1. 主流供应商实际协议、配置保存／切换／失败／密钥边界有定向验证；DeepSeek真实连接及模型回读。
2. 文字／CSV／PDF本机文字与支持视觉的模型图片整理，候选可修改、忽略、确认，重复提交不重复入库，原文与结果随实际 `.ka1` 恢复。
3. 自然语言期限／类型／关联查询返回真实详情入口；按币种精确金额汇总，不虚构答案。
4. 普通及重复待办创建、延期、完成；单订阅提前提醒；确认取消不写入、旧结果不可覆盖新数据、双击无重复。
5. 应用内与浏览器到期通知；权限拒绝可见，完成／暂停／取消／删除过滤，跨标签不重复；关页不声称继续推送。
6. 中英桌面／手机固定包与Ego原入口验证；源码提交、推送、固定包、CI、真实API及本机／互联网部署分别记录。

## 验收样例

- 合成账单“Studio hosting 每月 USD 12.50，2026-10-15续费”→订阅候选，核对币种／金额／日期后确认。
- “下个月要续费的订阅”→本机实际数据筛选与详情链接；“这个项目有哪些账号”→实际关系。
- “10月3日09:00检查域名，每月一次”→具体时区／时间／重复预览→确认。
- “这个订阅提前3天09:00提醒”→指定订阅覆盖配置，真实账期更新后通知规则仍按新账期。
- 提示注入、未知字段／对象、错误金额／日期、损坏响应、提供方失败、配置切换、锁库、重复确认均不能静默写入。

## 当前结果

本轮软件与本机固定包已实现：统一模型设置、AI 导入审核、自然语言本机查询、确认式任务与订阅提醒、应用内到期卡片、浏览器通知调度。首期通知范围按用户回复固定为「应用内＋浏览器通知，后台推送后续做」。

### 已有验证

- 用户明确授权后创建专用DeepSeek key，真实 `deepseek-flash` 连接、导入三条合成候选及重复回读、所选订阅分析、期限查找与US$12.50精确汇总、周期待办取消／确认／刷新、单订阅提前提醒保存均通过；真实一次性到期待办显示应用内卡片，完成后消失并刷新保留完成记录。密钥仅在会话，不落代码／日志／普通配置，原用户资料未发送。见 [真实API验收与边界](evidence/2026-10-01/deepseek-live/验收记录.md)。
- 修复真实模型暴露的可选null、JSON思考预算和金额最小单位误读后，最终包 `d4ec93e` 的 [AI矩阵](evidence/2026-10-01/deepseek-live/fixed-final.json) **19/19、50.491秒、0失败／跳过／flaky**。该矩阵是合成服务回归，与上项真实API证据分开记录。

- 模型适配器复用 AI SDK，覆盖 OpenAI、Anthropic、Gemini、DeepSeek、Qwen、Moonshot、MiniMax、OpenRouter，以及 Doubao／Ollama／自定义兼容服务。原生协议和失败／跳转／地址边界有合成测试；此清单表示已接入协议，不代表所有供应商真实 API 逐一通过。版本、来源与许可证见 [packages/ai/README](../packages/ai/README.md)。
- 导入复用既有审核与备份路径；AI 只能生成候选。文字／CSV／TXT／PDF 本机文字和支持视觉模型的图片已接线，未知币种／金额／周期保持待核对，避免把默认零金额当成真实账单。来源片段、审核状态及模型信息进入实际加密备份。不是独立本机 OCR。
- 检索只将问题转成有界计划，本机执行日期／关联筛选与按币种精确汇总；问答另由用户明确选择最多 20 条、合计 40,000 字符的安全字段。密码库与密钥不进入资料选择。
- 提醒预览包含对象、通知时间、IANA 时区、提前量与重复规则。取消不写入；确认后用当前任务／资产快照比较写入；周期完成、延期与编辑保留提醒语义。单订阅覆盖配置随实际账期变化。
- [最终固定包 AI 报告](evidence/2026-10-01/ai-acceptance/ai-fixed-final.json)：19/19、51.17 秒；中英五宽度问答／用量／失败与安全边界，中英 × 390／1280 的导入审核、查询真实详情、取消无写入、确认后刷新回读均通过。请求连接到本机合成模型服务，不是 DeepSeek 真实请求。
- [提醒运行时报告](evidence/2026-10-01/reminder-runtime-playwright.json)：应用内卡片、完整提醒摘要、跨标签／刷新去重及权限拒绝回退通过。系统通知对象使用测试替身，不能当成操作系统真实弹出证据。
- 当前固定包提交 `d4ec93e`；实际入口 `index-B7gedowB.js`，91当前文件逐字节一致、966已提交历史资源保留。原4186正常「Update app」加载同一脚本，旧资料与两条待办保留。此前83bbf2c证据仅作为前轮历史。
