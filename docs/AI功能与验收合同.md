# AI功能与数据边界

AI是保留的必要产品通道。收录页“AI整理”和顶部AI入口可达；配置提供商、模型、API地址及密钥后可测试连接。支持协议的清单见[AI包说明](../packages/ai/README.md)，接入协议不等于逐厂商真实服务验证。

普通整理支持文字、CSV/TXT和支持视觉的模型图片，不接收PDF。明确显示本次发送范围；普通通道拒绝显式密码。结果进入导入审核，确认前不写资产；取消、服务失败或不合法响应不能静默写入。

问答只发送用户选择的有限安全字段；检索计划在本机执行。生成待办/提醒需预览并再次确认。普通AI及MCP不能读取KDBX、密码或主密码。

长期API密钥保存在KDBX；会话模式仅在当前会话。锁库后长期密钥暂停使用，不记录密钥或敏感内容到日志。密码智能导入具有独立确认边界：确认模型、地址和可能包含密码的本次全文范围后才发送，不发送已有全库。

验证至少包括配置保存与锁定、失败恢复、文本/文件、敏感输入拒绝、取消无写、确认后刷新回读和重复确认防重。合成模型协议验证与真实厂商调用分别记录。证据放仓库外或test-results，不归档进源码。
