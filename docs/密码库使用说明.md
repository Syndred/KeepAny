# 密码库使用说明

进入侧栏「密码库」。已有的外部密码库引用保留在页面下方，本机加密密码条目显示在上方。

## 建立和使用

1. 输入至少12位的主密码并再次确认，点击「创建密码库」。也可以点击「导入并建立密码库」，选择仅用主密码保护的 `.kdbx` 文件并输入它的密码。
2. 点击「新建条目」，填写标题、账号和密码。可点击「生成密码」生成24位随机密码，填写网址、备注，并关联账号或其他资产。
3. 保存后可按标题、账号或网址搜索。点击「编辑」查看／复制密码；账号详情的「管理这个账号的密码」会筛选其关联条目。
4. 条目编辑会保留历史版本；「移入回收站」后仍可恢复。历史面板中的「恢复此版本」会保存为当前版本。
5. 点击「立即锁定」结束使用。页面隐藏、5分钟无操作或其他标签页更新会锁定；重新打开或刷新后须再次输入主密码。

## 一次导入多条密码

解锁后点击「智能导入」，粘贴清单或选择 UTF-8 编码的 CSV／TSV／TXT 文件，再点击「识别并预览」。每次最多200条、原文不超过2MiB。支持 Chrome 的 `name,url,username,password` 列，以及 Bitwarden 登录条目的 `name,login_uri,login_username,login_password,notes` 列；非登录类型会提示核对。

文字清单使用明确的字段名，每个字段一行，条目之间空一行，例如：

```text
标题=示例网站
网址=https://example.org/login
账号=demo@example.test
密码="示例密码;含分隔符和尾部空格  "

网址=https://example.com
账号=another@example.test
密码=另一条示例密码
```

也支持同一行用分号、竖线、制表符或逗号分隔的明确字段。密码包含分隔符、换行或需要保留前后空格时，使用上例的双引号形式（JSON 字符串转义）；不要把真实密码发送到外部聊天工具来整理。无法明确识别的行会显示行号和核对提示，不会猜密码。审核可修改标题、账号、密码、网址和备注，多行密码默认遮罩，显示后可核对原值。

也支持常见笔记清单：网站名（或网址）、邮箱账号、密码连续各占一行。编号／Markdown 标题和「登录账号／登录密码」等标签可识别。没有字段名时只生成待核对条目，默认不勾选，也不发送给 AI；核对密码后手动勾选。多出的邮箱、缺项和无法确定的行仍显示行号，不会自动丢弃或配给其他账号。

识别不完整时，点击「按行指定字段」。原文内容默认遮罩，可在本机显示、修正每行内容，为它选择标题、账号、密码、网址或备注；空行默认开始新条目，也可勾选其他起始行。未指定的行保留待核对，只有明确选择「忽略这行」才跳过；同一条目重复字段会提示修正。点击「预览指定的条目」再按正常审核流程保存。已修改但尚未指定的内容会在返回原文、部分保存后的继续核对中保留；关闭／锁库后清空。每次映射最多2,000个非空行，仍遵守200条／2MiB限制。

- 新条目默认勾选；相同网址和账号、相同密码的条目跳过。没有网址时以标题和账号判断。
- 相同身份但密码不同，默认保留现有条目。需要时选择「另存为新条目」或明确选择更新对象；更新保留旧密码历史。改动审核字段后需重新勾选。
- 点击「确认导入」后才保存为一份 KDBX 加密修订；预览和 AI 整理不会写库。其他标签修改后须重新解锁和核对，避免覆盖新版本。保存结果分别显示新增、更新、跳过数。
- 有未识别内容时，可在保存后点击「继续核对原文」。原文和候选仅留当前弹窗内存，关闭、锁库或刷新即清空；没有保存到普通收录候选、资产或日志。

可以直接核对保存，也可以复用「设置」中已经启用的 DeepSeek 或其他模型，点击整理网站名称。点击前可展开查看将发送的网站域名与临时条目编号；账号、密码、备注、原始标题、网址路径／查询参数／片段和完整原文不会发送。AI 只能从域名整理网站名称，不能改密码或直接入库；IP、本机地址和常见私有域名后缀不会发送，服务失败仍保留本机候选。它与「收录与备份」中的普通资料 AI 导入使用不同入口及保存路径。

## 备份和主密码

- 「导出备份」下载独立 `.kdbx` 文件，由当前密码库主密码保护。导入已有密码库时，需输入待导入文件自己的密码。
- 「收录与备份」创建的 `.ka1` 包含资料、附件以及本机密码库密文。外层备份密码和密码库主密码分别使用；恢复 `.ka1` 后，仍须原密码库主密码解锁。
- 修改主密码需要当前主密码。成功后新保存的库使用新密码，较早导出的备份仍使用导出时的旧密码。
- 本机已经有不同密码库时，整站恢复会拒绝覆盖。先分别导出保存两份密码库；需要合并条目时，在解锁后的密码库中导入 `.kdbx`，遇到无法安全合并的冲突会保留原库并提示失败。

## 当前支持范围

支持本机密码管理、文字／CSV／TSV审核式批量导入、KDBX3／4的主密码导入、独立或整站备份、已缓存应用离线刷新后解锁。密码条目不会进入普通资料搜索、AI问答、MCP或资产同步；智能导入的可选网站名称整理仅发送上述预览信息。KDBX导入上限16MiB，超出支持的加密参数会拒绝，原库仍保留。当前没有浏览器自动填充、跨设备密码同步、多人共享、key file或硬件挑战应答入口。

本机库属于当前浏览器与站点来源；换浏览器或清理站点资料不会自动转移密码。主密码没有后台重置入口，应自行保存主密码并保留可读的独立备份。
