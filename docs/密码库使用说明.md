# 密码库使用说明

进入侧栏「账号」，先设置或解锁主密码，再在同一个列表管理账号资料与登录。卡片直接显示可复制的账号、密码，网址图标在标题旁；编辑图标直接打开合并表单，不再经过登录详情弹窗。原 `/assets/account`、`/assets/vault` 入口同样进入统一账号页，条目定位、账号筛选与回收站链接保留兼容。

密码可以留空；没有单独的密码库分区或第二个解锁入口。密码、其他登录标识和私密备注仍保存在独立加密KDBX，普通资料不存密码。历史、回收站、批量导入、关联审核、改主密码和导入导出保留；锁定后整个账号列表和含私密资料的编辑表单隐藏，重新解锁不恢复旧的未保存表单。

设置中的「加入示例资料」提供 26 项虚构资料及 8 张本地图片，可以补充到已有工作区并防止重复加入。加入后，在「账号」解锁密码库，再主动点击「补齐示例登录条目」，可为这套示例账号加入登录条目，包括一个无密码示例；不会读取现有条目的密码。

## 建立和使用

1. 首次输入主密码并确认，点击「设置并进入」。至少需要6个字符，建议使用至少12位的长密码或短语。已有主密码时直接「解锁」。也可点「导入账号备份」，选择仅用主密码保护的 `.kdbx` 并输入原密码。
2. 点击「新增」，一次填写名称、分类、账号、可选密码和网址；更多账号资料中可填服务商、联系、用途、标签、状态、核实日期及普通备注。私密备注单独加密保存。编辑卡片时这些普通资料默认展开，常见字段不用重复填写。
3. 同一登录可使用邮箱、用户名或手机号时，点击「添加登录标识」，最多添加20个其他标识，它们共用这条记录的密码。不同小号使用独立登录：卡片「更多操作」→「新增登录」，填写其账号和密码。卡片账号行的切换图标每点一次切到下一个登录，同时切换对应密码和网址，无需下拉选择。
4. 保存后可按名称、任一登录标识或网址搜索。卡片多列排列，窄屏单列；长内容在卡片截断，完整资料进入同一个编辑表单查看。账号、密码旁的复制按钮复制原值；密码默认隐藏，复制无需先显示。切换、筛选或锁定会隐藏已显示的密码。标题旁网址图标打开当前登录地址。
5. 标题旁删除图标只删除当前切换的登录，确认前会显示对象，其他登录和账号资料保留。当前标识与同条记录其他标识共用密码时，从历史版本恢复；独立登录进入下方「登录回收站」，可恢复。历史、新增登录与解除关联在卡片更多菜单；备份、智能导入、关联审核和主密码在标题栏账号选项。没有登录的普通账号卡片显示「移入回收站」，可在侧栏回收站恢复。
6. 点击「立即锁定」结束使用。页面隐藏、5分钟无操作或其他标签页更新会锁定；重新打开或刷新后须再次输入主密码。

## 关联账号与族谱

解锁后在标题栏「账号选项」菜单选择「关联账号」，勾选要加入普通账号资料的登录，核对名称、主登录账号、分类和网站域名。每批最多200条，空登录账号与专用 AI 密钥条目不参与。邮箱／手机本体会建议对应分类，其他服务默认「其他」，可以改成已有分类；已有非空分类保留。已有账号的公开字段变化会显示「更新账号资料」及原名称、账号供核对。

保存的公开字段，以及勾选的邮箱／手机号身份节点和关系，属于普通账号资料，会进入普通备份／已配置同步。身份节点也可能来自本次所选条目的其他登录标识。密码、原备注和完整密码条目继续保存在 KDBX；编辑关联线索不回写原备注。

- 勾选条目后自动核对全部登录标识，「本机匹配」可重新核对。服务连接到实际邮箱／手机号身份，同一身份复用现有记录；国内手机号与 `+86` 写法合并，学号、QQ 等普通数字用户名不当成手机。相同标识不代表第三方登录或找回方式，相关建议需另行核对。
- 同时核对普通账号中使用相同邮箱／手机号的已有账号，包括已关联密码条目的附加登录标识。保存勾选的关系，不改这些已有账号的名称、网址、分类或备注，也不导入未勾选的新密码条目。邮箱账号自身不重复连向自己。
- 在「账号」中保存资料时，也会复用已有邮箱／手机身份建立登录关系；先保存服务、后建立邮箱／手机身份，同样会补齐已有服务。手动删除的关系不会因普通资料编辑而自动恢复。
- 「AI 关联建议」发送主动勾选的名称、全部登录标识、网站域名与当前关联线索，点击前显示模型和地址。线索默认预填本条备注，可直接修改或清空；检查后点击分析才发送，编辑线索不改原备注。超过500字符会保留完整内容并提示删减。AI 不会收到密码字段、主密码或未选条目。分析也包含本机标识匹配，不必先点本机识别；Google 登录／找回建议默认不勾选，逐条确认后才保存。
- 保存后密码卡片出现账号链接；打开默认查看直接关联，可切换「完整关系」查看间接连接。当前账号居中，关联账号按分支数量分布到两侧，密集时使用紧凑卡片。箭头从使用方指向登录标识／登录或找回账号，左右位置不改变方向。节点显示名称和账号标识；其他账号可点击打开完整资料。搜索高亮匹配，保留连接路径；下方列表可以打开对应账号。列表卡片显示唯一直接关联数量。账号详情仍可管理该账号的密码，「显示全部」会同时清除地址筛选，刷新后保留全部展示。
- 可拖动画布，或使用工具条中的放大、缩小、视图切换和全屏图标。全屏内点击其他账号、浏览器前进／后退均保持全屏；按 Esc 或关闭按钮返回。视图切换在「适应画布」与「回到当前」之间切换，小图只保留有必要的操作；节点较多时，小地图支持点击定位和拖动。名称与账号标识相同时只显示一次。

关联审核出现「需要处理」时，具体条目会显示原因和操作：

- **原账号在回收站**：已删除账号不再阻止导入。再次主动选择该条目并保存会建立新账号，或复用明确匹配的现有账号；旧账号继续留在回收站，不会自动恢复。保存会清除本条目对旧已删除账号的关联。
- **有多个匹配账号或想换绑**：在「改用已有账号」选择目标，再核对公开资料并保存。保存会用本条目的名称、登录账号和网址更新所选账号；会移除本次更换的旧账号关联，保留其他资产关联。密码和备注仍保存在原加密条目。
- **重新添加已删除的关系**：核对建议中，已删除的关系会显示说明并默认不勾选。需要恢复时主动勾选，再保存；恢复同一条关系，不重复新建。已彻底删除的其他账号关系不会因这次补齐而重建；需要重建时主动选择对应账号重新关联。若审核后关系又被修改或删除，请关闭后重新核对。
- 问题条目也可搜索定位；暂不处理时可继续保存其他已选条目。
- 图上不逐线重复铺写用途。点击连线，或用 Tab 定位后按 Enter／空格，查看来源、目标、用途与核验状态；选中线加粗，其余线淡化。同一对账号的多种用途在图上合为一条方向线。说明框可直接点「删除关系」并确认，把这条连线的全部关系移至回收站；明细中仍可逐条删除。账号和密码保留，删除最后一条线也继续留在全屏。图中删除键不改资料。
- 再次关联旧资料时，保存前会提示将清理的旧自动标识关联数量。仅清理本次所选账号中能确认来源的旧随机中心、误判数字或过期标识关系；人工编辑和未选账号的关系保留。多个有效匹配或身份资料变更时单独提示选择目标，其余条目可继续。邮箱／手机本体仍有独立身份记录时，不能在此直接更换其主标识。
- 重复关联复用原账号和关系，不重复新建；先写普通账号资料，再批量更新 KDBX 关联。若后一步因锁库／写入失败未完成，已保存账号保留，再次解锁并关联可继续。密码库变化时须重新核对，旧导入草稿不会被清理。

## 解除关联与回收站

- **解除密码与账号的关联**：卡片「更多操作」→「解除关联」，确认后断开；普通账号和加密登录都保留。未关联的登录继续用相同卡片显示。
- **删除普通账号**：进入账号详情，点右上角「移至回收站」并确认。账号相关连线停止显示，密码条目保留；以后可以直接重新关联，不需要先恢复旧账号。
- **找回普通账号或图上的关系**：使用侧栏「回收站」，手机先展开侧栏；加密登录使用账号页下方的「登录回收站」。


## 一次导入多条密码

密码为可选项：Google 等第三方登录可留空，可在备注写明登录方式；无密码的新条目仍需主动核对。CSV／TSV 同时有名称和账号列时也可省略密码列。

列表中的「核对原文」表示有原文尚未归入字段，不表示一定缺少密码。检查账号、密码与备注；有遗漏可填入对应字段或加入备注，信息无误可以不改字段，直接点击「完成核对」。

核对过程中可随时点击顶部「新增账号」，补录 AI 漏掉的独立账号；名称、账号、其他登录标识、密码、备注和网址旁都提供复制与粘贴，复制隐藏的密码仍得到完整原值。其他登录标识逐行显示，操作按钮分别排列。

不需要的候选或「核对原文」可以点击「删除这条」并确认，从本次导入清单移除；不会删除密码库中已保存的账号，也不会改写原始清单。「暂时跳过」则保留这条待处理。其他记录若有补入被删目标的未提交填写，仍可在「更换条目」找回，并明确选择「作为新账号核对」。查看「已核对」时，本次最近核对的条目排在前面，顺序随加密草稿保存。

解锁后点击「智能导入」，粘贴清单或选择 UTF-8 编码的 CSV／TSV／TXT 文件，选择「用模型识别清单」或「本机识别并预览」。本机每次最多200条、原文不超过2MiB。支持 Chrome 的 `name,url,username,password` 列，以及 Bitwarden 登录条目的 `name,login_uri,login_username,login_password,notes` 列；非登录类型会提示核对。

文字清单使用明确的字段名，每个字段一行，条目之间空一行，例如：

```text
名称=Gmail
账号=demo@example.test
密码="示例密码;含分隔符和尾部空格  "

名称=示例 App
账号=reader-demo
密码=另一条示例密码
```

也支持同一行用分号、竖线、制表符或逗号分隔的明确字段。密码包含分隔符、换行或需要保留前后空格时，使用上例的双引号形式（JSON 字符串转义）；不要把真实密码发送到外部聊天工具来整理。需要核对的内容直接显示对应原文片段，已确认的名称和账号可见，密码及尚未归属的文字默认遮住；点击「显示密码」只显示当前片段。每行原文末尾可直接复制；已识别字段复制其实际值，包含引号转义的密码会解码并保留空格、换行。表单中名称、账号、其他登录标识、密码、备注和网址旁可点击粘贴，替换当前字段；读取剪贴板失败时仍可用键盘或系统菜单粘贴。不会猜密码。审核表单直接显示备注，可添加其他登录标识；没有网址时只显示「添加网址」，多行密码显示后可核对原值。

本机识别也支持常见笔记清单：名称（邮箱、App 或网站）、账号、密码连续各占一行；App 用户名可用已配置的模型识别或手工指定字段。编号／Markdown 标题和「登录账号／登录密码」等标签可识别。没有字段名时只生成待核对条目，默认不勾选；本机识别不会联网，核对密码后手动勾选。多出的邮箱、缺项和无法确定的内容保留为原文片段，不会自动丢弃或配给其他账号。

识别不完整时，核对页展开表单，已确认的名称和账号自动带入。原文每行可复制，字段旁可粘贴；多行值保留原来的空白和换行。原文中的密码和不明内容默认遮住，可逐片段显示。

表单默认补全唯一可确认归属的条目，无需先选择新建方式；同平台不同小号不因名称相同自动合并。需要另建或补充其他条目时，点「更换条目」后明确选择。核对后点「完成核对」，完整新条目会自动勾选，再点「确认导入」入库；缺项填写先保留，补齐后才可入库。已有库条目发生重复／冲突时仍须明确选择保存方式。整个补填流程不重新调用 AI。名称、账号和单行密码输入框统一高度；添加登录标识位于账号旁，备注直接显示，添加网址位于备注旁，网址仍可不填。
片段填写、完整／待补卡和普通条目编辑都可增删其他登录标识。导入核对卡也提供「新增同平台账号」：新增独立待补卡，只带入名称和网址，原卡的密码、备注、登录标识和勾选不复制。补齐新卡后核对、勾选再入库；新建小号和补填不会再次调用模型。

收起表单、更换条目或切换目标以及返回其他输入方式都保留当前填写；未改内容的已有目标不能应用。完整条目可以先入库，剩余片段仍留在核对页；片段表单里未提交的填写也保留。可继续新建，或明确补充本次已经入库的条目；后者更新同一条目并保留历史，不重复新增。识别结果、核对选择、未提交的表单填写和按行指定进度会自动加密保存到本机密码库。看到「草稿已加密保存」后，关闭、锁库、刷新或更新应用，再解锁并打开「智能导入」即可继续；恢复不调用模型。

「其他输入方式」保留修改原文和按行指定字段。进入后可直接「返回核对」，已有候选、修改、勾选及未提交表单仍在；只有成功重新识别才替换本次结果。按行指定时，原文默认遮罩，可修正内容并明确选择名称、账号、密码、网址或备注；空行默认开始新条目，也可勾选其他起始行。初次输入点击「预览指定的条目」，已有结果时点击「将指定条目加入核对列表」只追加成功条目，不替换 AI 结果。失败块不会被当作已处理；只有明确选择「忽略这行」才跳过。如果换了原文且还有未解决内容，需完成指定或明确忽略后再追加，避免遗漏。每次映射最多2,000个非空行，仍遵守200条／2MiB限制。

- 本机明确字段且有密码的新条目默认勾选；无密码条目需主动核对；AI识别及无字段名推断的条目核对后手动勾选。相同网址和账号、相同密码的条目跳过。没有网址时以标题和账号判断。
- AI审核会显示实际使用的模型与地址，以及完整／待补条目数量。缺少名称或已填写的网址有误的条目会保留为可编辑表单，修正后再核对；完整条目可先保存。AI不会补造缺失的密码。
- 相同身份但密码不同，默认保留现有条目。需要时选择「另存为新条目」或明确选择更新对象；更新保留旧密码历史。改动审核字段后需重新勾选。
- 原库已有相同密码时默认跳过；若手工补充了备注等信息，需明确选择「更新」对应条目才能保存补充内容。密码不变时不会重复新建，也会保留修改前的历史。
- 点击「确认导入」后才写入正式密码条目；预览与编辑仅保存独立加密草稿，不计为条目。其他标签修改后须重新解锁和核对，避免覆盖新版本。保存结果分别显示新增、更新、跳过数。
- 部分保存后，未选条目、未提交表单及修改仍留在审核页，可以继续补充和保存；即使只剩原文片段，也能在旁边填表后入库。原文、候选及未提交填写仅保存到独立 KDBX 的加密草稿，不进入普通收录候选、资产、日志或同步。关闭默认保存草稿；只有明确选择「关闭并清空」才丢弃草稿，全部导入后自动清除。密码库在此期间有正式变更时，结果和修改仍保留，但需重新核对选择。保存失败会显示重试提示并阻止直接关闭；加密保存尚未完成时不要刷新。独立 KDBX 导出／整站加密备份也包含未完成草稿，请按密码备份保管。

可以直接核对保存，也可以复用「设置」中已经启用的 DeepSeek 或其他模型，点击整理网站名称。点击前可展开查看将发送的网站域名与临时条目编号；账号、密码、备注、原始标题、网址路径／查询参数／片段和完整原文不会发送。AI 只能从域名整理网站名称，不能改密码或直接入库；IP、本机地址和常见私有域名后缀不会发送，服务失败仍保留本机候选。它与「收录与备份」中的普通资料 AI 导入使用不同入口及保存路径。

### 使用已配置的 AI 识别笔记

在输入清单后点击「用模型识别清单」。这会把本次粘贴的完整清单（包括账号、密码和备注）发送给设置中已经启用的模型，按钮前显示模型和 API 地址。不会读取或发送已有密码库和主密码；API Key 仅用于对应服务的认证。云端数据处理由所选服务负责，不能承诺零留存。识别结果需核对，勾选后再确认入库。

模型判断记录分组和原文位置，本机取原文值，保留空格、标点和换行；明确引用的 JSON 字符串在本机解码。模型可识别同一账号的其他登录标识，每项都须精确引用原文；不同小号仍分别成条。重复邮箱标签不会被本机擅自当作同一账号合并。缺项、虚构／歧义引用、遗漏或被 AI 标为忽略的行仍提示核对，不会自动填相邻账号的密码。全文识别最多等待120秒，取消立即终止，不会自动重复发送。模型漏写可空字段或部分记录无效时，保留其他可验证条目；所有未覆盖原文仍待核对。超时、输出截断和无法读取的格式分别提示原因，失败保留原文和已有结果，可重试或本机识别；已加密保存的草稿可在关闭、锁库和刷新后恢复。每次 AI 最多40,000字符、2,000行和200条，大清单分批处理。

复用「设置 → 连接 AI 模型」中的 DeepSeek 等云端服务，也可选择「其他 OpenAI 兼容服务」，填写自己已有的模型地址和模型名。自部署服务支持本机 HTTP 回环地址（localhost／127.0.0.1／::1）或远端 HTTPS，服务需允许浏览器访问；无认证服务可选择「服务无需密钥」。KeepAny 不下载模型，不要求安装 Ollama。模型设置中的「加密保存，长期使用」可直接输入 API Key 保存到密码库，也可选择已有条目；选择「解锁密码库后自动启用此密钥」并保存后，刷新／重新打开只需解锁，不必重输 API Key。锁库停止使用，修改其他密码条目不会停用该密钥；所选密钥更新后使用新值。旧手动配置仍可点击「启用已选密钥」，无需退出导入。「仅本次使用」不会长期保存密钥，刷新／关闭后需重新输入。

## 备份和主密码

- 「导出备份」下载独立 `.kdbx` 文件，由当前密码库主密码保护。导入已有密码库时，需输入待导入文件自己的密码。
- 「收录与备份」创建的 `.ka1` 包含资料、附件以及本机密码库密文。外层备份密码和密码库主密码分别使用；恢复 `.ka1` 后，仍须原密码库主密码解锁。
- 修改主密码需要当前主密码。成功后新保存的库使用新密码，较早导出的备份仍使用导出时的旧密码。
- 本机已经有不同密码库时，整站恢复会拒绝覆盖。先分别导出保存两份密码库；需要合并条目时，在解锁后的密码库中导入 `.kdbx`，遇到无法安全合并的冲突会保留原库并提示失败。

## 当前支持范围

支持本机密码管理、文字／CSV／TSV审核式批量导入、KDBX3／4的主密码导入、独立或整站备份、已缓存应用离线刷新后解锁。密码条目不会进入普通资料搜索、AI问答、MCP或资产同步；主动核对保存的关联账号元数据按上节说明进入普通资料；智能导入只有主动选择全文AI识别时发送本次清单，另有仅发送域名／编号的网站名称整理。KDBX导入上限16MiB，超出支持的加密参数会拒绝，原库仍保留。当前没有浏览器自动填充、跨设备密码同步、多人共享、key file或硬件挑战应答入口。

本机库属于当前浏览器与站点来源；换浏览器或清理站点资料不会自动转移密码。主密码没有后台重置入口，应自行保存主密码并保留可读的独立备份。
