# 密码库使用说明

进入“账号”设置或解锁主密码。名称、账号、可选密码、网址与一份备注在统一表单管理；账号卡片直接复制登录资料，多个登录可切换。名称进入关联和待办页面。

密码、私有备注和长期API密钥保存在独立KDBX，不进入普通资料搜索、普通AI或MCP。忘记主密码没有后台重置入口，请妥善保管。

账号选项支持KDBX导入导出、密码库维护和审核式智能导入。AI智能导入前应核对模型、地址和本次全文发送范围；结果核对后才写库。示例密码只在明确操作后写入已解锁的库。

“备份与恢复”的KA1包含本机密码库密文。恢复后仍需该库原主密码；与现有库冲突时应用会拒绝覆盖。请在隔离浏览器配置中验证备份恢复。
