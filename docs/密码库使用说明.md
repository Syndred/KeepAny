# 密码库使用说明

进入“账号”设置或解锁主密码。名称、账号、可选密码、网址与一份备注在统一表单管理；账号卡片直接复制登录资料，已有多个登录可切换。右上打开网址，右下提供新增、编辑和删除。新增只继承当前卡片的名称、网址、分类，填写后保存为独立新卡片，不复制账号、密码、备注或关联。点击名称进入详情，使用历史版本、解除关联、复制网址、查看关联和待办。

密码、私有备注和长期API密钥保存在独立KDBX，不进入普通资料搜索、普通AI或MCP。忘记主密码没有后台重置入口，请妥善保管。

Mac 桌面版解锁时可勾选「在这台 Mac 上记住主密码」。首次正确解锁后，应用把该库的解锁凭据存入本机钥匙串。以后进入锁定页，可选择「使用本机钥匙串解锁」，也可通过「取消记住主密码」移除凭据。恢复密码库备份或更改主密码仍需要主密码。

账号选项支持KDBX导入导出、密码库维护和审核式智能导入。AI智能导入前应核对模型、地址和本次全文发送范围；结果核对后才写库。示例密码只在明确操作后写入已解锁的库。

分类、搜索和账号操作集中在账号页工具栏。卡片删除的密码条目可到侧边栏“回收站”查看和恢复，锁定时先解锁。普通资料与密码条目在同页分区显示，清空和彻底删除仍需确认，密码条目及其历史仍只保存在独立KDBX。

“备份与恢复”的KA1包含本机密码库密文。恢复后仍需该库原主密码；与现有库冲突时应用会拒绝覆盖。请在隔离浏览器配置中验证备份恢复。
