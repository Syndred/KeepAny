# 开发与验证

## 草图格式与摘要卡交互

KeepAny 的草图、线框图、效果预览以及每轮设计修改，只能以 PNG、JPG 或 WebP 图片在对话中展示。不能用 HTML、可交互草图、visualize 嵌入或网页链接代替图片。可编辑源只作为内部制作资料，先渲染为图片再给用户看。

资产摘要卡点击整张卡片进入详情，并支持键盘进入；不额外增加“展开资料”“收起资料”等重复入口。详情页原有的按需展开区不受影响。图片方案确认后才实施；图片通过不代表正式页面已验收。

## 开发与检查

使用Node.js 22+、pnpm 11.10.0。先读README和当前交接，检查git状态并fetch；只在无覆盖风险时快进。

- 普通资料由RxDB本机仓库持有；密码和长期AI密钥只进入独立KDBX。
- 数据schema、存储键、KA1/KDBX及旧兼容标识不得因清理或更名改写。
- UI文案用zh-CN/en键；沿用统一主题，先画草图并确认方案，再实现布局。
- 改动前按需求写覆盖ID、前置资料、入口/步骤、状态、预期与方法；结果绑定实际编译候选。
- 功能、白盒、视觉、主控本人实际操作与独立复核分别记录。未验、失败、版本不匹配均不能称完成。
- 使用隔离虚构资料；修前失败与修后复测证据放仓库外或忽略的test-results，不能删用例、放宽预期或重试凑绿。
- UI至少实际检查中英390/768/1280/1920及反馈尺寸，覆盖展开、错误、焦点、禁用和长内容等适用状态。共享控件换容器须重新验证。

常用命令：

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm build:preview
pnpm verify:preview /absolute/path/to/compiled-candidate.zip
node scripts/check-cleanup-ux.mjs /absolute/path/to/compiled-candidate.zip /new/evidence/directory
node scripts/build-catalog-candidate.mjs /new/compiled-web-directory
# 设置 KEEPANY_WEB_CANDIDATE 为上一步目录后：
node scripts/check-catalog-categories.mjs /new/category-evidence-directory
```

浏览器交付检查须显式设置KEEPANY_PREVIEW_DIRECTORY或KEEPANY_PREVIEW_ARCHIVE之一，使用最终编译候选。日常入口为daily.yml；完整发布检查由verify.yml手动运行。历史冻结档案校验已退出当前CI；真实路由恢复、密码历史及当前候选布局等业务回归继续保留。机器检查只能证明列出的身份/结果/几何，不能证明人工视觉已完成。

仓库只保存代码、必要测试、当前指南和许可。截图、日志、ZIP、历史交接及本次验收报告不再提交。用户使用确认后再正式打包发布。

分类检查使用明确编译的Web候选及CANDIDATE.json绑定源码和页面摘要，覆盖CAT01–09、CAT12–13以及双语390/768/884/1280/1920状态。它不生成正式发布ZIP。主控本人体验（CAT10）、独立复核（CAT11）和人工逐张视觉仍须单独记录；daily中已配置机器入口不代表云端已运行。

## 统一账号详情检查（2026-11-05）

账号解锁后使用统一详情，不按历史数据来源区分界面。关系图下方按模板来源、同号码／邮箱与同名线索展示相关账号；登录信息旁提供图标操作，备注随内容定高，历史记录直接恢复。详情取消独立待办、影响清单、更多操作卡和重复查看关联入口。历史待办资料继续保留于备份及现有提醒兼容路径。

`node scripts/check-account-detail-approved.mjs <新证据目录>` 必须消费明确的编译候选（本机可设置 `KEEPANY_WEB_CANDIDATE`，CI沿用预览包选择），校验候选摘要、AS01–05/AS08–10结果、中英五宽默认/hover/focus/pressed/说明展开/关联明细展开/全屏/长内容图片清单，无跳过或自动重试。已配置daily入口；配置存在不表示云端已经执行。AS06整合提醒、AS07独立复核、主控本人体验及逐图目检分别记录。

默认短内容桌面使用一屏；主动展开或长标题、长网址、长备注及历史组合超出可读最小空间时，页面自然增加高度，不裁切卡片。截图须等待异步关系图完成，默认入口先消除前一状态遗留焦点并回到页面顶部；调整尺寸后保留滚动位置的图片只能标为该状态，不能冒称默认入口。

账号历史恢复同时核对可见名称、账号、网址、备注、关系图与刷新回读，保留当前版本并校验旧列表。仅加密库来源的账号与已有资产投影的账号都要从可见入口重放。模板来源仅进入加密KDBX；没有来源记录的旧资料不能推断为同模板。机检通过不代表功能、视觉、白盒、主控体验或独立复核全部完成。
