# 00 产品范围与开放边界

## 已确认

品牌工作名 KeepAny。首发面向有多个项目和平台账号的独立开发者、创作者；实物为完整但不无限扩展的配套模块。功能足够，进入实现和真实流程验证，不再持续堆模块。

### 开源核心

- 概览、待办、项目、账号、订阅、实物、本机加密密码库与外部密码库引用。
- 自定义分类、标签、侧栏手柄拖动、全局搜索、关系图。
- 项目网站/仓库/工具；网站描述、Logo、截图、投递资料、外链记录。
- 账号邮箱/手机/社交分类；有方向、带来源和核实时间的关系；换绑清单。
- 订阅与付款方式/账号/项目关联；月付、年付、自定义周期、试用、优惠阶段；月均和实际付款分开。
- 实物照片、购买使用日期、保修、位置、借出归还与历史。
- 快速收录、去重预览、回收站、完整导出/恢复。
- 本地离线读写、可自部署的同步基础实现、公开协议。
- 自带模型、基础AI工具层、MCP接口、存储连接器。

### 可收费的官方服务

省配置的同步托管、存储配额、自动备份与历史保留、官方模型额度、持续运行的维护检查与通知。收费点是托管/算力/存储/运维，不封锁本地资料和完整导出。

### 首期不做

银行卡完整凭据、投资交易系统、食品出入库、完整笔记/日历、自动代替用户登录换绑/取消第三方服务。家庭多人共享和密钥分发放后续，数据模型预留workspace，不把复杂家庭共享作为首发门槛。

2026-09-30 用户要求“把密码功能跑通”，本机密码库从原首期排除项改为核心功能：复用 KeePass KDBX 引擎，独立密文存储、主密码解锁和 KDBX／整站备份；原密码库引用不迁成密码。浏览器自动填充、Bitwarden 服务登录与跨设备密码同步另列后续，详见 [ADR 0016](adr/0016-本机密码库与KDBX备份.md)。

## 信任承诺与限制

本地无需注册；浏览器首次加载或安装仍需取得应用文件。数据默认在本设备，不自动上传。云同步与AI分别启用；用户选择资料与提供商。PWA本地存储可能因清除站点数据/浏览器策略丢失，必须有持久存储提示与备份，不能承诺浏览器存储永不丢失。

停止付费不锁本地功能；官方服务到期/云端保留期须公开。同步不等于备份。发布前用实际恢复测试证明导出完整，不凭“下载成功”判断。
