# 00 产品范围与开放边界

## 定位与当前方向（2026-10-13）

**StackPerch 是独立开发者的本地数字资产工作台，把项目、域名、账号、订阅和维护关系连起来。**

StackPerch 原名 KeepAny。公开介绍页、下载与源码继续使用既有 KeepAny 入口；原浏览器、原地址的数据和旧 `.ka1`／`.kdbx` 备份可沿用。

首期面向同时维护多个网站、SaaS 或副业项目的人，优先解决三个具体问题：

1. 一个项目依赖哪些登录账号、域名、订阅和设备？
2. 更换邮箱、手机号或停用账号时，哪些已记录的服务需要检查？
3. 停止维护一个项目后，还有哪些费用和维护事项需要处理？

实物与密码库保留为本地核心的一部分，不把家庭库存或通用密码管理器作为唯一定位。首期提供简体中文和英语。当前以本地测试版的可理解、可安装、可恢复和实际使用为优先；**商业功能暂停扩展**，官方托管及付费服务尚未开放。

## 完整本地核心开源

本地读写、关系、整理和完整导出不以注册、付费或官方服务在线为条件。

| 范围 | 内容 |
|---|---|
| 资料与关联 | 项目、账号、订阅、实物；分类、标签、搜索和关系图；关系来源、方向与核实时间 |
| 项目维护 | 网站／域名／仓库记录、外链台账、账号变更检查清单、关联待办 |
| 费用与设备 | 订阅账期、试用与优惠阶段、月均及本机付款记录；实物保修、位置、借还与历史 |
| 收录和恢复 | 审核式收录、去重、回收站、图片、加密 `.ka1` 备份及恢复 |
| 密码与模型密钥 | 独立加密 KDBX 密码库、主密码解锁、导入导出、审核式批量导入，以及外部密码库引用 |
| 可选集成源码 | 自部署同步基础实现与公开协议、自带模型工具层、MCP 与存储连接器；按各自验证边界开放 |

域名当前记录在项目与维护事项中，不提供注册商接管或自动续费。付款记录只说明本机台账，不是支付凭证。换绑清单仅依据已记录关系生成，完成表示用户记录了检查，不代表第三方已更新。

密码功能为用户已确认的核心范围，复用 KeePass KDBX 引擎。密码不写入普通资产、全局搜索、MCP 或常规资产同步；原外部密码库引用不自动迁成密码。参见 [ADR 0016](adr/0016-本机密码库与KDBX备份.md)。

## 未来可选付费托管

收费方向是省部署、省维护的托管服务：同步托管、存储、自动备份与历史保留、持续运行的通知和支持。官方模型额度也可作为独立的算力服务，但不要求本地用户使用官方模型。

上述方向不是当前已提供服务，不预售未完成的同步、安全或后台通知。上线前须公开服务范围、价格、配额、取消与到期规则，并完成生产验收。停止付费不能锁住本地 CRUD 或完整导出；同步不替代备份。

商业网站、订单、会员与运营后台保持在独立商业仓库 KeepAnyAdm。不得把 ShipAny 模板、商业后台源码、密钥或生产数据带入本仓库。见 [商业项目拆分](07-ShipAny商业项目拆分.md)。

## 数据与发送边界

默认资料位于当前设备的浏览器存储，按浏览器配置和站点来源隔离。相同浏览器下的 `http://127.0.0.1:4180/`、`http://localhost:4180/` 和开发端口各自存储；改变地址不是迁移。浏览器清理、存储配额或策略可能删除本地资料，不承诺永不丢失。用可读的下载备份完成恢复验证。

`.ka1` 包含普通资料、图片、历史、收录审核与本机密码库密文；密码库仍由自己的主密码保护。主密码与备份密码没有后台重置入口。实验性同步的工作区密钥与授权凭据不放入普通资料备份，需另行保管。

AI 与同步分别启用。普通 AI 问答仅发送用户选择的有限字段；普通收录不默认读取密码库。独立密码智能导入的全文 AI 识别，在用户主动确认模型、地址与发送范围后，允许发送本次清单全文，包括其中的账号、密码和备注；不读取或发送已有全库及主密码。候选由用户审核后才写 KDBX。识别与核对草稿保存在独立 KDBX 的加密草稿中，普通资产及日志不保存这些秘密。准确范围见 [AI 合同](AI功能与验收合同.md) 和 [密码库说明](密码库使用说明.md)。

## 当前不做或未开放

- 银行卡完整凭据、投资交易、食品出入库、完整笔记与日历。
- 自动登录第三方、自动换绑或自动取消服务。
- 浏览器密码自动填充、跨设备密码同步与多人密码库共享。
- 官方托管、后台邮件与关页推送；Gmail 读取和回填仍待实现。
- 实验性同步、账户绑定、MCP 或连接器的生产可用性承诺；普通试用不依赖这些能力。

真实手机、完整平台矩阵、低存储和断电恢复、生产安全与云端验收仍按 [阶段清单](06-开发计划与验收清单.md) 管理。测试通过说明对应版本和场景，不等于所有功能零缺陷。
