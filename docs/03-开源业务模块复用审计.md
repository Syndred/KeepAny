# 开源业务模块复用审计

核查日期：2026-09-28。范围：HomeInventory、Wallos、DomainMOD、Homebox 的公开许可证与指定源文件。结论属于静态源码抽查，不是完整安全审计、安装验收或生产性能认证。

2026-09-30 范围追加：真正的本机密码功能采用 `kdbxweb 2.1.1` 与 `hash-wasm 4.12.0` npm 依赖，沿用 KeePass 格式和上游密码算法；不复制 HomeInventory Personal Vault。固定上游发布 commit、许可证、受限解压 patch、保留的适配测试与备份边界见 [ADR 0016](adr/0016-本机密码库与KDBX备份.md)。下文原“Personal Vault 不复用”指该应用的耦合业务源码，不再表示 KeepAny 排除全部密码功能。

## 1. 决策摘要

| 项目 | 实际技术与许可证 | KeepAny 决策 | 复用粒度 |
|---|---|---|---|
| asdteke/HomeInventory | React/TypeScript 前端；Express JavaScript + better-sqlite3 后端；MIT | 实物借还、维护、附件业务的首选移植候选 | 抽取纯规则及用例；重接统一资产、权限、存储接口 |
| ellite/Wallos | PHP + SQLite；GPLv3 | 首期做数据导入；周期计算、费用规则作为移植候选 | 不能当 TypeScript 包安装；需明确许可并改写适配、补边界测试 |
| domainmod/domainmod | PHP + MySQL；GPLv3，已查文件头标为 v3-or-later | 首期参考字段与支持 CSV 导入；注册商优先官方 API/SDK | 不复制现有 HTTP 客户端；后续按注册商逐个核验 |
| sysadminsmedia/homebox | Go + Vue；AGPLv3 | 数据迁移与验收用例参考；不把整套应用嵌进 KeepAny | 可独立连接已有实例；当前不复制 Go/Vue 实现 |

**已确认“有可参考和改造的源码”，未确认“整模块复制后就能运行”。** 四者都不是可以 npm 安装的通用资产业务库。避免重复造轮子，应优先直接依赖 UI、上传、图谱、解析、同步等成熟库；业务应用则按耦合成本选择移植或适配，不能为了复用而引入四套登录、数据库和运行时。

本文件不宣称已把任何上游业务代码导入 KeepAny。阶段 0 只选一个 MIT 借还规则做提取验证，通过后再扩展；当前核心暂不混入 GPL/AGPL 源码，保持许可证选择空间。

### 当前仓库复核（2026-09-28）

本轮对 `packages/`、`apps/` 的源码检索了四个上游项目名、组织名与核心业务路径，未找到标记为四者来源的导入文件；现有借还/维护字段和页面行为不能据此认定为从上游提取。尚未进行跨仓库代码相似度或逐行来源鉴别，因此“没有检索命中”不等于法律上的原创性结论。UI 中存在 `shadcn/ui composition pattern` 注释，使用 Radix Slot 与 class-variance-authority；这属于另一个组件来源线索，发布前需连同实际文件来源一并复核。

当前 [NOTICE](../NOTICE.md) 与 [SBOM](../SBOM.spdx.json) 只覆盖安装的 npm 包，不包含四个未导入应用的源码许可证；若后续采用本文候选规则，须先补齐固定上游 commit 和原文件路径，再更新清单、测试及兼容性判断。当前没有通过本文件确认 GPL/AGPL 业务源码已可组合分发。

### 为什么需要改造

- `items.js` 超过 2,000 行，耦合 SQL、加密字段、家庭成员、文件系统、路由和活动日志。无法当作一个独立包搬入浏览器本地数据库。
- 后端主要是 JavaScript，不是全栈 TypeScript。前端使用 TypeScript 不代表后端逻辑可直接复用类型。
- 维护日期采用 `setUTCMonth` / `setUTCFullYear`，默认存在月末溢出语义。KeepAny 必须明确“1 月 31 日下次月付/维护”的策略，不能直接照搬到账单计算。
- 部分服务端错误文案仍直接写成土耳其语。提取时转换为稳定错误码，在 zh-CN/en 词典显示；不把上游全部语言搬入产品。
- 图片筛选使用扩展名与 MIME 声明；正式上传还应验证实际可解码内容、大小和像素限制。私有附件不能因沿用公开静态目录而泄露。

### 不复用

整套用户登录、Personal Vault 密码保险库、购物清单、全部语言包、桌面启动器、生产 secret 管理代码和现成 UI 页面。上述内容与 KeepAny 首期边界不同，且不是已审计的安全基础。

### 候选提取验收

单件物品不能同时有两条有效借出；非所有者无法结束他人的记录；重复归还幂等；删除/归档保留必要历史；离线修改可恢复；日期边界覆盖月末、闰年；附件失败不留下无主文件。两种语言显示一致。

## 4. DomainMOD：注册商与域名

来源：[仓库](https://github.com/domainmod/domainmod)、[LICENSE](https://github.com/domainmod/domainmod/blob/master/LICENSE)。

真实文件包括：

- [classes/DomainMOD/Cloudflare.php](https://github.com/domainmod/domainmod/blob/master/classes/DomainMOD/Cloudflare.php)：`getApiUrl`、`apiCall`、`getDomainList`、`getFullInfo`。
- [classes/DomainMOD/Namecheap.php](https://github.com/domainmod/domainmod/blob/master/classes/DomainMOD/Namecheap.php)：域名列表、分页参数、DNS/隐私/自动续费信息处理。
- `classes/DomainMOD/Porkbun.php`、`GoDaddy.php`、`Gandi.php`、`Dynadot.php`：注册商适配文件存在；本轮没有全部逐行核验，不认定当前 API 可用。
- [assets/add/registrar-account.php](https://github.com/domainmod/domainmod/blob/master/assets/add/registrar-account.php)：注册商账号管理入口。

**本轮明确发现的不能照搬点：** Cloudflare 适配器的 `apiCall` 设置 `CURLOPT_SSL_VERIFYHOST=false` 和 `CURLOPT_SSL_VERIFYPEER=false`，并使用 `X-Auth-Email` / `X-Auth-Key`。KeepAny 不继承关闭 TLS 验证的做法，不默认要求用户提供全局 API Key。

实施选择：

1. 先支持 CSV 手动导入和域名/注册商/账号关联，用户未配置 API 也可用。
2. 自动化从 Cloudflare 只读连接器开始，依据现行官方 API/SDK，确认可用权限和分页；存在源码不代表接口权限对每个账号开放。
3. 外部服务返回 `observedAt`、来源、同步状态，错误时保留上次资料，不把“查不到”当删除。
4. Namecheap、Porkbun 等按用户需求逐个接入，不为了复用而提前支持所有注册商。

复用的是已经明确的字段语义、映射经验和数据迁移路径；需要复制代码时按 GPL 处理。只读域名列表、实际续费费用、余额、自动续费开关是不同权限和能力，不能用一个“已连接”状态冒充全支持。

## 6. 许可证与复用边界

- MIT：保留原版权及许可声明，确认选取文件和依赖没有单独许可证。新文件需要记录来源、修改内容。
- GPLv3：复制或改编代码后，分发组合的许可与源码提供义务需要纳入工程方案；不能简单把所有代码统一标成 MIT。
- AGPLv3：除了分发，还需关注修改版通过网络提供服务时的对应源码义务。不把 AGPL 代码混入闭源 ShipAny 商业仓库。
- GPL 与 AGPL 能否组合、如何向用户提供源码，取决于具体版本、文件许可和组合方式；“都开源所以随便混”不成立。
- 单独进程加 API 也不是自动免除许可义务的保证。只通过公开格式导入用户数据，与复制其实现不同。

工程默认：第一阶段采用直接依赖的宽松许可库和经过登记的 MIT 提取模块。所有 GPL/AGPL 代码移植进入单独决策记录后才能开始。此为实现约束，不代替发布前针对具体组合的许可证核验。

## 8. 阶段 0 交付与停用标准

1. HomeInventory 借还状态提取为独立纯业务模块，接 KeepAny 资产标识；保留 MIT 声明和相关测试来源。
2. 与本地数据库、软删除及关系数据协同验证；不允许因借还模块另起 SQLite 后台。
3. 若提取必须连带上游整套身份/家庭/加密/服务器，则停止搬路由，改为复用验证过的纯规则与用例，登记原因。
4. Wallos 导出样例导入后，数量、币种、周期、日期可回读；金额不允许默认为美元。
5. DomainMOD 只读字段映射与分页契约确认，TLS 校验开启，不要求多余写权限。
6. 所有用户可见文案仅 zh-CN/en；自动错误、空状态和导入报告同时验收。

最终模块选择以阶段 0 的可运行验证为准。当前可以确定技术方向与文件候选，但尚未完成业务代码提取和集成验收。
