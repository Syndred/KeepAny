## 完成

- 账号和项目详情均内联同一图组件，保留直接／完整关系、所有端点、原始箭头方向、已核验实线／待核验虚线。每个原始 relation.id 都有独立视觉连线、ELK 端口、来源、核验日和编辑／移除按钮；同端点多关系和反向关系均可分别点击，不静默聚合或整组删除。
- 编辑保留原 ID、方向和创建时间，使用 `saveRelationIfCurrent`。标签／来源复用现 domain 约束，新增的核验日期要求有效日历日期或留空；旧记录的原有日期值在未修改时保留。缺来源／日期显示“未记录”。
- 并发冲突保留草稿及当前数据，展示最新标签／来源／核验值；用户明确核对后才更新编辑基线，再次保存仍受 CAS 保护。目标已删除时给出错误，不空转或显示成功。
- 始终可搜索；支持缩放、画布拖动、节点拖动、聚焦当前／适应全图、展开／收回。节点偏移、筛选和相机仅为有上限的当前页签内存状态，不进入资产、备份或同步。跳转到另一类资产后，图工具栏可直接返回，展开状态下也可返回。
- 展开相机按邻近节点与相对偏移换算到新布局，收回及节点返回保持原视角、筛选和拖动位置。拖动后的连接线使用 React Flow 自带路径工具跟随端点；初始布局继续使用 ELK 避障路径。
- 详情内可恢复每条删除关系的原 ID。历史恢复列表独立于活动图：即使删除间接边导致分支断开、随后刷新页面，仍可从原详情恢复；已删除节点／关系不会桥接活动图。关联资产不可用时禁用恢复，清除后的记录不提供恢复。

## 首次失败、修复与复验

| 发现 | 归类、修复与复验 |

| 展开时节点返回按钮在弹窗外 | 自 review 发现并修复：返回操作进入图工具栏，展开图中的跨类型跳转返回已实际验证 |
