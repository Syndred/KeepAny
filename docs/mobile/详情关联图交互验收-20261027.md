# 详情关联图交互验收

日期：2026-10-27。分支：`codex/mobile-app`。账号／项目共用现有 React Flow、ELK 和关系数据，补齐交互，不修改普通资产 schema、ID、备份／同步协议或 KDBX。

## 完成

- 账号和项目详情均内联同一图组件，保留直接／完整关系、所有端点、原始箭头方向、已核验实线／含待核验虚线。相同有向端点可共用一条视觉连线，但选中后每个原始关系 ID 都有独立行、来源、核验日和编辑／移除按钮；不再提供静默整组删除。
- 编辑保留原 ID、方向和创建时间，使用 `saveRelationIfCurrent`。标签／来源复用现 domain 约束，新增的核验日期要求有效日历日期或留空；旧记录的原有日期值在未修改时保留。缺来源／日期显示“未记录”。
- 并发冲突保留草稿及当前数据，展示最新标签／来源／核验值；用户明确核对后才更新编辑基线，再次保存仍受 CAS 保护。目标已删除时给出错误，不空转或显示成功。
- 始终可搜索；支持缩放、画布拖动、节点拖动、聚焦当前／适应全图、展开／收回。节点偏移、筛选和相机仅为有上限的当前页签内存状态，不进入资产、备份或同步。跳转到另一类资产后，图工具栏可直接返回，展开状态下也可返回。
- 展开相机按邻近节点与相对偏移换算到新布局，收回及节点返回保持原视角、筛选和拖动位置。拖动后的连接线使用 React Flow 自带路径工具跟随端点；初始布局继续使用 ELK 避障路径。
- 详情内可恢复每条删除关系的原 ID。历史恢复列表独立于活动图：即使删除间接边导致分支断开、随后刷新页面，仍可从原详情恢复；已删除节点／关系不会桥接活动图。关联资产不可用时禁用恢复，清除后的记录不提供恢复。

## 点击 → 预期 → 实际

浏览器采用隔离 4234、合成普通资产，英文／中文、390×844／1280×844；每种语言宽度都走账号和项目两个中心。固定资料通过真实仓库 API 建立，以下操作通过实际 React 页面进行。

## 首次失败、修复与复验

| 发现 | 归类、修复与复验 |
| --- | --- |
| 真实关系 CAS 冲突只显示通用错误 | 产品问题：底层旧接口对关系载荷冲突返回 `asset-stale`。页面兼容识别该代码和 `relation-stale`，草稿／最新内容核对重试已实测 |
| 编辑来源／核验后连线消失 | 产品问题：关系刷新后节点连接点测量失效。随关系刷新和测量状态重新更新 React Flow internals，编辑、删除／恢复和旧图回归复验通过 |
| 展开时节点返回按钮在弹窗外 | 自 review 发现并修复：返回操作进入图工具栏，展开图中的跨类型跳转返回已实际验证 |
| 只记录近期删除 ID 无法保证刷新后恢复间接边 | 自 review 发现并修复：从普通记录建立独立历史恢复视图，刷新后恢复、删除端点禁用、purged 排除均验证 |
| 手机测试拖动位置落在固定底栏；按钮名称与既有文案不符 | 测试夹具问题：滚到真实节点中心并读取现有中英文名称，未改产品文案迎合测试 |
| 直接动态导入状态模块的断言受 Vite HMR 双模块实例影响 | 测试夹具问题：浏览器改为断言实际 DOM 位移、展开／返回后的位移和仓库资产不变；内存状态隔离另有单测 |
| 原测试读取整行文字／通用 details 类造成误匹配 | 测试适配：标题断言精准选择关系标题，保留原标签断言；历史恢复使用独立 class，未放松旧图几何、核验、备份恢复断言 |
