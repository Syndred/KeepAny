4. 修改名称、中篇介绍及内部备注，点击取消；重新进入编辑，14项和分类必须恢复原值。
5. 只更改名称并保存，再终止冷启；进入同名项目编辑器，核对新名称及其他所有字段、分类保持，最后取消关闭编辑器。

## 长表单与证据设计

新增可达性 helper 沿用既有 `tapReachable` 的几何约束，并支持向上/向下滚动。它先在真实资产页测量底栏上边界，模态层使底栏从 AX 隐藏时保留该实际测量值；点击前要求控件完整处于 WebView 横向范围、顶部下方和底栏/实际键盘上方。原 `tapReachable` 本身未改。无法找到分组、分类、Select All 或安全点击位置时保留失败和 AX，不跳过断言。

- `project-text-fields-<language>-before-save.json`
- `project-text-fields-<language>-cold-start-edit.json`
- `project-text-fields-<language>-after-cancel.json`
- `project-text-fields-<language>-renamed-cold-start.json`
- 对应阶段截图及 `-AX` 层级、保存后截图、冷启详情、投递素材截图/AX、冷启项目链接 AX。

主控另拥有 workflow，已约定仅对白名单前缀项目的 Native `records` 输出 `{recordId,payload}` NDJSON。本片没有修改该 workflow，也尚无新 dump。后续必须将 JSON 预期与 Native SQLite 逐字段比较，能获得初始链接 ID 时还要核对改名前后同一 ID。**AX 名称/编辑值、源码断言和最终 SQLite 一行都不能独自证明初始 ID 未变；若初始 ID 不可获取，该项继续待补证。** 未执行或中途失败的阶段不得因附件模板存在而记通过。
