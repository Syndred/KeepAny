## 隔离方法

每项测试在真实 `getNoBackupFilesDir()` 下创建自己唯一随机子目录；`ContextWrapper` 同时覆盖 `getApplicationContext()` 返回自身、`getNoBackupFilesDir()` 返回该子目录，防生产构造函数丢弃隔离上下文。生产 `keepany-mcp-authority-v1` 路径因此只会出现在本测试子目录内。

所有 dataset scope 为随机UUID的SHA256；alias仅为这些随机scope的生产前缀。仅使用自造 metadata ID/hash/字段名，不含真实授权、密码或业务字段值。不读取/枚举其他alias；目录清理只递归本次随机子目录并校验canonical边界。没有 chmod 主应用共享目录，没有访问普通SQLite、KDBX、Prefs、私密controller、CA或9445/6/7。
