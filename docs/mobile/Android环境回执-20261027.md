## 环境故障与处理

1. 命令行工具安装在 SDK 外，`avdmanager` 初次写出了额外 `android-sdk/` 前缀；仅修正本 AVD 的 `image.sysdir.1` 为实际镜像绝对路径，并设置当前启动进程的 `ANDROID_HOME`/`ANDROID_SDK_ROOT`。
2. 初次 qemu 启动退出 `0xC0000135`。仅对本次启动的临时进程启用 loader 诊断，确认它没有搜索包内 `lib64` 的 DLL；在 qemu 目录为原包 `lib64/*.dll` 建立硬链接后，qemu `-version` 正常。没有复制系统 DLL、修改系统 DLL 搜索设置或安装运行库。
3. `-gpu software` 在本主机退出 `0xC0000005`；`-gpu host` 配合 WHPX 实际启动成功。没有修改 GPU 驱动。第一次失败保留在本机 `test-results/native-environment/`。

工具根保存 `start-keepany-emulator.ps1`，用于准备上述独立 AVD 并以隐藏无窗口方式启动。脚本不会占用其他 AVD，5580 已占用时会拒绝再开实例。当前实际运行的是同参数的前台执行会话，保持在线供后续原生复验；目标收尾时正常关闭该设备。
