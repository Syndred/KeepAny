## 首次失败、调查与复验

1. 首轮4项中3项通过；workspace401。夹具漏带现协议要求的`X-KeepAny-Account-Id`，而Cookie与identity已成功。只修测试请求，加上明确的“缺头仍401”负例；生产服务边界未改。`jvm-first.xml`保留。
2. 第二轮登录/权限与另外两项通过；测试control原子替换遇Windows `AccessDeniedException`。具体共享句柄owner未取证，不能指认为生产HTTP故障。测试控制写加入两秒内10ms间隔的有界重试，未改网络/业务超时。`jvm-control-red.xml`保留。
3. 一轮4/4绿但总54秒，S3/WebDAV40.312秒、故障链10.195秒；运行中实际读control为10秒delay，与前次finally恢复失败的残留影响相符。补每个受控运行的初始默认归位，随后四项总约1秒。该轮未约束cancel自身，不能据总时间声称取消及时或死锁。
4. 补cancel本身1500ms预算、真实Socket read阶段与可选线程栈采样。两次实际cancel=1ms，故障链0.743秒/最终0.156秒，没有触发阻塞栈采样。`jcmd`附加尝试时目标后来已结束，AccessDenied不算死锁证据。最终没有证实生产锁阻塞，因此没有凭猜测修改`ConnectionsHttp`。
5. 最终新HTTPS 4/4、原邻近软件合同3/3，Gradle `BUILD SUCCESSFUL in 3s`。新4项分别0.162/0.421/0.266/0.156秒。没有重跑无关全量。

## 重跑方法与证据

仅在主控确认 fixture control/Gradle 窗口空闲时运行。需由私密JSON程序生成properties：保留字符串字段；`accounts[n]`下字符串映射为`account.n.<字段>`；Java properties转义反斜杠/换行/制表符，UTF-8无BOM。不把实际值写进命令或仓库。测试显式要求 `KEEPANY_HTTPS_FIXTURE_DIR`；未配置时属于未具备测试fixture，不算通过。

在`apps/mobile/android`运行：

```powershell
$env:KEEPANY_HTTPS_FIXTURE_DIR = '<私密 fixture 目录>'
# JAVA_HOME/ANDROID_HOME/ANDROID_SDK_ROOT为本机既有工具链；JAVA_TOOL_OPTIONS使用既有短目录。
.\gradlew.bat :app:testDebugUnitTest --tests io.github.syndred.keepany.ConnectionsHttpsTest --tests io.github.syndred.keepany.ConnectionsHttpTest
```

收尾恢复control默认并删除临时properties。证据目录：`C:/Users/Administrator/.codex/toolchains/keepany-mobile/evidence/f21-https-20261027/`，`jvm-final-summary.json`（仅方法/布尔/时长）、`jvm-final-https.xml`、`jvm-final-adjacent.xml`、`jvm-cancel-first-bounded.json`、`jvm-cancel-timing.json`与前述红回执。原始private JSON/CA私钥/登录正文/签名链接未复制入仓库。
