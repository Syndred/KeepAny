## 三个产品问题与兼容审查

1. **D-F06-01同名目标**：`page-asset-detail.tsx`原SelectOption只渲染a.name。实际两语popup option文字均为“选择资产/Select an asset、F06 same name、F06 same name”，用户不可按账号标识区分。`relation-target-labels.ts`仅在同名时添加普通username、非账号公共hostname与译类型；可见内容仍相同追加稳定8字符ID，短前缀冲突使用完整ID。唯一名称保留原exact label，选值仍原ID。5个C验证同名、相同标识ID兜底及前缀冲突、唯一标签兼容、URL秘密不入标签。产品独立提交`af95ac6d`。
2. **D-F06-02显式方向**：初版只有隐含“当前→所选”，无可操作方向字段，不能按原步骤填方向。新字段复用统一Select与现有form-grid，局部direction选项最小44px，四个双语key独立relation-copy接i18n；创建才选择from/to，编辑始终沿relationEditBase原from/to。标准schema、原记录ID/createdAt和关联恢复协议不改。方向重复检查使用实际有向端点；反向可另建，不能借编辑调换旧端点。方向产品独立提交`c1019740`。

3. **D-F06-03必填错误反馈**：原空/空格用途只能看到Save禁用，不能解释失败原因。新增触碰后提示，最初打开不显示错误；有效输入立即清该字段提示，取消后重新打开重置触碰态。HTML required及ARIA属性与可见错误同源，独立key，不改date/stale/form状态和旧日期schema。实际两语清空→blur红→绿、取消重开、合法输入→原日期错误→更正仅一条保存均有独立回执。产品独立提交`47b38feb`。

没有复制上游业务源码或新增依赖。说明文字仅帮助用户判断“既有方向不改、反向另建”，没有把API/CAS/SQLite等实现说明塞入UI。
