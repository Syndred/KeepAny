## 公共源码依据与定位

固定使用 [PDF.js v6.3.289 的官方 `src/display/api.js`](https://github.com/mozilla/pdf.js/blob/v6.3.289/src/display/api.js)，并核对本机发布产物 `pdfjs-dist/legacy/build/pdf.mjs`：22844 行创建局部原始 Worker，22866 行注册 `test` 回包处理，22874 行才把它赋给 `#webWorker`；22921–22927 行的 `destroy()` 仅终止已经赋值的 `#webWorker` 并清理已赋值 handler。公开 [API 文档](https://mozilla.github.io/pdf.js/api/draft/api.js.html) 的当前草案可能已调整握手，不用草案的最新消息名替代本机固定版本。

当前产品通过公开 `PDFWorker.create()` 创建 owner，并在原截止点 finally 调用其 `destroy()`；此次握手未成功，局部 Worker 尚未进入这个 owner 可终止的字段。因此 UI 截止正确但原 Worker 所有权存在空窗。以上是由本次观测与固定源码结合得出的定位；未触碰私有字段或宣称所有初始化失败均会泄漏。
