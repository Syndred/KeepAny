# 手机草图功能覆盖与缺口核对

日期：2026-10-27。用户反馈：“功能有漏吗，怎么关联图不见了”。这是对草图的纠正记录，不能作为正式应用或真机功能验收。

## 结论

**上一版有遗漏，也有过度简化。** `62aeba8` 将“关联图”改成普通关系记录表；保留编辑入口不等于保留图。原35项抽样只验证关系表单，没有断言节点／连线，未检出这个缺陷。因此撤回“完整交互”这一笼统标题，改称“功能交互草图”，并公开本清单。

本轮恢复实际可点击的节点与有向连线、实线／虚线核验状态、来源与核验日、节点跳转与返回、关系增改删与回收站、缩放／拖动／适应／聚焦／展开／搜索／核验筛选。账号和项目详情直接有图，“更多”另有独立入口。图与编辑、回收站共用同一组内存演示关系，删除关系不会删节点或资产。

## 与既有功能去向表逐项比较

“可演示”只表示虚构资料的页面操作，不表示原生功能已实现；“简化／缺口”明确列出后续要补的设计。

## 设计与验证约束

- 后续实现以[完整功能去向合同](手机功能整合与完整覆盖-v2-20261027.md)及现有产品为准，不能把上表缺口解释成批准删功能。缩短手机导航只允许重新分组。
- 正式关联图复用 `apps/web/src/account-family-graph-view.tsx`、`account-graph-layout.ts` 与React组件／统一变量。当前SVG只为可丢弃草图，不复制为正式图引擎。
- 本轮无新增依赖、无上游代码复制；节点／箭头和交互为本地草图实现，图标继续使用原Lucide许可素材。
- 原35项演示回归与15项关联图专项分别记录，不累计冒充产品覆盖率；关系测试改为从真正的图上选择边再编辑／删除／恢复。中英360／390／430与实际应用内预览另核对。
- 功能清单尚有上述明确设计缺口，**不能宣称无遗漏或已经完整保留所有细节**。本轮修复关联图，不以存在入口替代后续完整设计。
