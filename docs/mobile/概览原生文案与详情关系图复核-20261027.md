## 详情关系图：源码复核结果

这部分为源码证据，未在本片重复关系图端到端测试，不记为原生交互验收通过。

| 能力 | 账号详情 | 项目详情 |
| --- | --- | --- |
| 内联完整图 | `AccountFamilyGraphView` 内联 React Flow，自定义节点及布局 | `page-asset-detail.tsx` 的另一 React Flow 分支，基本节点及连线 |
| 多端点、同端点多关系 | 保留全部关系 ID；相同有向 `[from,to]` 分组，反向独立 | 同样按有向端点分组；标签过多时摘要显示，明细保留每条 |
