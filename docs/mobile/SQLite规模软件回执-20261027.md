# SQLite 规模软件回执

日期：2026-10-27；运行时源码包含 `5e297705`，新增探针脚本另行提交。环境 **C**：Windows 10.0.26200、Node 24.21.0、实际磁盘 SQLite 3.53.4，CPU为Intel Core i5-12400F。不是 Android/iOS 插件、手机内存或 React 启动指标。

命令：`node --import tsx scripts/benchmark-native-storage.mts`，退出码0。每个规模使用独立磁盘库，正式 schema/NativeRecordBackend 校验批量建立合成项目与账号，关闭重开共享 LocalRepository，再读全表筛关键词、编辑原ID、导出真正加密 KA1、解密恢复到另一空库。最后逐行比较完整记录，另读回被编辑的原ID/描述，三个规模全部一致。临时库已关闭并仅清理本次已验证目录。
