# UI 组件与密度约定

2026-10-28，用户确认统一采用最新稳定版 shadcn + Base UI + Tailwind。

## 实际实现

| 层级 | 实现 | 职责 |
|---|---|---|
| 框架 | React 19.3.0 + TypeScript | React 组件、表单和领域页面 |
| 组件源码 | shadcn 4.23.0 CLI，base-nova | 官方 Base UI 组合方式；源码归项目维护 |
| 交互基础 | @base-ui/react 1.9.0 | Button、Dialog、Select、Popover、Menu、Input、useRender |
| 样式 | Tailwind CSS / @tailwindcss/vite 4.3.3 | 真实样式入口、utilities、@theme 和公共变量 |
| 日历 | @daypicker/react 10.0.2 + date-fns 4.4.0 | 中文／英文日历、月份年份、键盘导航和合法日期 |
| 图标／拖动 | 现有 Lucide / dnd-kit | 图标与可访问排序；不新增另一套 UI 组件库 |

直接 Radix 依赖及其源码引用已移除。shadcn 是可维护的组件源码，不是运行时大包；CLI 作为精确版本开发依赖保留。上游提交、文件路径、MIT 原文与修改说明在 [SOURCE.json](../legal/third-party/shadcn-ui/SOURCE.json)。

`apps/web/src/components/ui/` 统一维护按钮、文本链接、表单输入、下拉、弹窗、菜单、浮层及日期。页面只组合这些控件；Textarea、复选框等保留适合其语义的原生 HTML。Base UI 与原生表单、链接的正常语义保持一致，导航与下载不能被改成按钮角色。

`styles.css` 是 Tailwind 和主题入口，颜色、间距与轮廓变量集中定义。基础控件样式只有一个维护位置。领域样式只负责其布局、事实信息和响应式规则，不向页面追加脚本或从参考 HTML 叠加修补样式。没有用框架迁移替换数据仓库、协议或兼容标识。

## 展示规则

- 默认紧凑列表：名称与图标同排，期限、费用、状态横向扫读；内容决定行高，不为缺少的资料保留大块占位。
- 卡片视图可切换，所有入口共用视图偏好。卡片最多 360px，按可用宽度排布；实际图片使用标题旁缩略图，完整图片在详情中查看。
- 同排卡片高度和底部操作对齐；公共旧列表选择器不影响卡片布局。概览最多6张限宽项目卡，短页头与实际动作同行；已启用提醒使用紧凑横条，不能为提高密度隐藏提醒。
- 项目没有实际截图时，不生成假网页或装饰封面。长标题与说明最多两行，详情保留全文。
- 分类用连续紧凑行：图标、名称、数量及操作同排。右侧编辑器独立；窄列使用可键盘操作的更多菜单。
- 文字操作使用统一椭圆按钮；图标按钮、输入框与选择框按各自语义使用不同轮廓。账本金额使用等宽数字，操作列宽度一致。
- 日期整块可点，图标不再是唯一触发点。输入接受 `YYYY-MM-DD`，非法日期不写入；有必填、清空、禁用、上下限、键盘与焦点返回语义。
- 手机日期格、前后月、分类更多及其菜单项保持44px触控区；桌面文字操作按钮可用较紧凑高度，仍共用椭圆轮廓。没有维护计划时待办列表独占可用列。
- 所有新增用户文案进入 i18n key。开发实现说明不进入用户页面。
