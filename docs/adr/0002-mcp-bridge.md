# ADR 0002：MCP 独立进程与浏览器本地仓库的桥接边界

日期：2026-09-28。状态：**协议及本地测试实现；正式 Web 接线和用户验收待做**。

## 决策

沿用官方 MCP SDK 的 stdio 服务及既有 `McpAuthority`，不创建第二份可写资产库。独立 Node 进程通过 `startLocalMcpBridge` 在 `127.0.0.1` 的系统分配端口运行单浏览器会话 RPC。浏览器在自己实际运行的 IndexedDB 来源里，用 `RxdbMcpAssetStore` 执行请求。桥本身不签发 MCP 权限，也没有 HTTP 的“列出全库”接口。真正对模型输出的资产与字段仍由 `McpAssetService` 按授权裁剪。

可信启动器必须先让用户选择资产、可读字段、可写字段与有效期，并通过既有 `issueGrant` 签发权限。启动器以可信 UI/进程 IPC 将**精确桥 URL 与配对密钥**交给当前 Web 应用；不得写入 MCP stdout、URL、浏览器持久存储或普通日志。Web 应用拿到配对返回的作用域后，必须展示并调用一次 `approve(scope)`；拒绝时不启动请求循环。写入另走既有的准确预览、用户批准、版本比较与幂等回执，桥配对并不等于写入批准。

## 协议和限制

| 步骤 | 检查与状态 |
|---|---|
| 启动 | 仅绑定 `127.0.0.1:0`；可信启动器固定一个精确 `appOrigin`，HTTP 仅允许 loopback 来源，远端 Web 必须 HTTPS。启动时重新检查 grant。 |
| `/pair` | POST JSON；校验完整 `Host`、`Origin`、随机 256 位配对密钥与两分钟期限；只能成功一次，返回随机会话密钥、最多 15 分钟期限及授权资产/字段范围。 |
| `/poll`、`/respond` | POST JSON；完整 `Host` 和 `Origin` 加 Bearer 会话密钥；每次请求使用随机 UUID、10 秒默认期限、一次响应，迟到或重放拒绝。最多 16 个未决请求；响应正文不超过 1 MB。 |
| 数据 | 浏览器仅回传已授权资产的 `id/kind/createdAt/updatedAt/deleted` 最小元数据与获批可读字段。Node 拒绝额外字段、越界资产 ID 与重复 ID。写入在浏览器端读取原始 RxDB 记录并按获批可写字段合并，保留未获批字段；`compareAndSet` 再查版本。 |
| 撤销 | 桥在每个 RPC 前、浏览器轮询时及结果返回前重查 grant；桥进程退出丢弃会话和未决请求。授权撤销后新请求拒绝，已有写入可能形成既有 `operation-uncertain`，须人工核对，不自动重放。 |
| 日志 | 桥不记录请求正文、配对/会话密钥、资产内容或字段值；既有权限审计只记 ID、字段名、动作与结果。HTTP 错误只给固定错误码。 |

没有 Cookie 或宽泛 CORS。预检仅向固定来源返回 `POST` 与 `Authorization, Content-Type`；缺失/`null`/其他 `Origin` 均拒绝。`Host` 必须等于实际 `127.0.0.1:<端口>`，阻断通过其他域名指向 loopback 的 DNS rebinding 请求。配对密钥本身才是本地进程鉴别凭据；端口号或 `Origin` 单独都不是身份凭据。

## 威胁模型与剩余风险

| 威胁 | 处理或剩余风险 |
|---|---|
| 恶意网页、跨源请求或 `Origin: null` | 精确 Origin/Host、随机密钥、CORS 与非 Cookie 会话；无法仅靠探测端口配对。 |
| 同机恶意进程扫描端口、伪造 Origin | 进程可以伪造 HTTP 标头，但没有通过可信渠道交付的 256 位密钥仍不能配对。若它能读取启动器内存、浏览器进程或同账户私有文件，不能以本桥承诺隔离；应使用操作系统进程/账户权限。 |
| DNS rebinding | 仅监听数值 loopback，且校验实际 Host；不将 `localhost`、任意域名或网卡地址作为服务端 Host。 |
| 配对码泄露或浏览器 XSS | 配对码一次性、两分钟；会话不持久化、最多 15 分钟。XSS 能在已授权 Web 来源内读取会话并借用浏览器数据权限，Origin 无法防同源脚本；正式接线前须完成 CSP、外部 HTML 处理和浏览器安全审查。 |
| nonce 重放、延迟响应 | 每次 RPC 随机 ID、超时、完成即删除；重放/迟到拒绝。超时写入保留“结果不确定”语义，不能盲重试。 |
| 撤销与在途请求竞争 | 多处重查可阻止多数在途读回；已经提交到 RxDB 的操作无法瞬时撤回，须保留操作回执和人工核对。 |
| 泄漏未授权字段 | 浏览器投影后再出域，Node 拒绝额外字段；MCP 输出再次按授权裁剪。资产 `kind` 及基本时间仍会暴露给本地 Node 进程，需在 UI 说明。 |

## 验证与未完成

`packages/mcp/src/bridge.test.ts` 使用真实 loopback HTTP 验证来源/Host、一次配对、错误 Bearer、浏览器投影、隐藏字段保留、撤销、nonce 重放和超时；既有服务测试覆盖 MCP 工具协议、预览批准与操作幂等。`pnpm typecheck` 与包内 Vitest 是实现门槛。

**未完成**：正式 Web 授权/批准 UI、可信启动器与 MCP 客户端配置、浏览器真实跨源/CORS 和 PWA 混合内容验证、应用关闭/重开及进程间验收、安全审计。这一实现不能直接宣称普通用户已可通过 MCP 访问浏览器资料，也不能开放默认无鉴权 localhost 全库接口。
