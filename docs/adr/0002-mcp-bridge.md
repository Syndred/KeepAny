# ADR 0002：MCP 独立进程与浏览器本地仓库的桥接边界

日期：2026-09-28；2026-09-29 补充可信配对交付与写批准决策。状态：**开发版 Web 接线和隔离浏览器联调完成；正式打包与生产验收未完成**。

## 正式接线决策（2026-09-29）

1. 正式 Web 设置页从当前 RxDB 订阅的资产中由用户明确选择资产、可读/可写字段和有效期，下载仅含所选 ID/字段、页面精确 origin、创建时间与随机请求标识的启动请求 JSON。请求文件不含授权或配对密钥，但包含可识别资产 ID，应由用户保管。浏览器不执行命令，不自动启动本机进程。用户自行把该请求文件路径放进本机 MCP 客户端配置。
2. 独立 stdio 启动器校验请求文件类型、时效、schema、origin 和 scope，调用 `McpAuthority.issueGrant`，在随机 loopback 端口启动桥；把精确桥 URL、一次性配对密钥、请求标识和两分钟期限写到本机受限 `0700` 目录内的新建 `0600` 配对文件。文件不得是符号链接或覆盖既有路径；配对成功、超时或进程退出后由启动器删除。MCP stdout 仅供协议，密钥不进 stderr、URL、浏览器持久存储或普通日志。Web 通过用户主动选取该文件读取到当前页面内存，严格比对请求标识、origin 和已选 scope；展示范围并由用户再批准一次，批准后才进入轮询。拒绝时撤销/关闭；本机同账户恶意进程可读浏览器或私有文件仍超出本桥承诺。
3. MCP `preview_asset_update` 只生成待批预览，不批准。Node 将该预览的准确旧值/新值和期望版本置于仅当前配对会话可读的内存控制队列；正式 Web 通过带 Bearer 的精确 Origin/Host 通道读取，再对同一 RxDB 记录重查版本，显示逐字段旧/新值。用户另点批准，Node 再次核对预览与当前版本后调用 `approvePreview`；拒绝、过期、撤销均不能确认。模型工具不暴露批准接口，不能仅凭预览 ID 自批。原有 compare-and-set、持久幂等回执与结果不确定时拒绝自动重放保持。
4. 浏览器运行时与批准对话框挂在持续存在的 Web 应用根组件，而不依赖设置页生命期；切路由不丢连接。页面关闭尽力撤销并中止轮询，失败时桥的会话和请求期限仍作最终边界；独立 stdio 进程退出立即关闭 loopback。正式 Web 只导入浏览器安全子模块，不能把 Node 文件/stdio/crypto 实现打进客户端包。
5. 显式撤销先在浏览器端取消后续写入，等待已经进入存储适配器的写操作结束，再向桥请求持久撤销；只有桥确认后才显示撤销成功。浏览器执行器在读取后、进入 CAS 前，以及 RxDB `incrementalModify` 每次修改回调和重试时检查取消、请求/会话期限，并向桥复核当前请求、会话和 grant。若写已越过最后可取消点交给存储，撤销等待它结束并在界面提示用户核对资料；落库后应答丢失维持 `operation-uncertain`。撤销 HTTP 失败保留会话以便重试，不显示已撤销。

## 决策

沿用官方 MCP SDK 的 stdio 服务及既有 `McpAuthority`，不创建第二份可写资产库。独立 Node 进程通过 `startLocalMcpBridge` 在 `127.0.0.1` 的系统分配端口运行单浏览器会话 RPC。浏览器在自己实际运行的 IndexedDB 来源里，用 `RxdbMcpAssetStore` 执行请求。桥本身不签发 MCP 权限，也没有 HTTP 的“列出全库”接口。真正对模型输出的资产与字段仍由 `McpAssetService` 按授权裁剪。

可信启动器必须先让用户选择资产、可读字段、可写字段与有效期，并通过既有 `issueGrant` 签发权限。启动器以可信 UI/进程 IPC 将**精确桥 URL 与配对密钥**交给当前 Web 应用；不得写入 MCP stdout、URL、浏览器持久存储或普通日志。Web 应用拿到配对返回的作用域后，必须展示并调用一次 `approve(scope)`；拒绝时不启动请求循环。写入另走既有的准确预览、用户批准、版本比较与幂等回执，桥配对并不等于写入批准。

## 协议和限制

| 步骤 | 检查与状态 |
|---|---|
| 启动 | 仅绑定 `127.0.0.1:0`；可信启动器固定一个精确 `appOrigin`，HTTP 仅允许 loopback 来源，远端 Web 必须 HTTPS。启动时重新检查 grant。 |
| `/pair` | POST JSON；校验完整 `Host`、`Origin`、随机 256 位配对密钥与两分钟期限；只能成功一次，返回随机会话密钥、最多 15 分钟期限及授权资产/字段范围。 |
| `/poll`、`/respond`、`/check-write` | POST JSON；完整 `Host` 和 `Origin` 加 Bearer 会话密钥；每次请求使用随机 UUID、10 秒默认期限、一次响应，迟到或重放拒绝。写入每次实际修改回调前用 `/check-write` 核对未决请求、会话与 grant。最多 16 个未决请求；响应正文不超过 1 MB。 |
| 数据 | 浏览器仅回传已授权资产的 `id/kind/createdAt/updatedAt/deleted` 最小元数据与获批可读字段。Node 拒绝额外字段、越界资产 ID 与重复 ID。写入在浏览器端读取原始 RxDB 记录并按获批可写字段合并，保留未获批字段；`compareAndSet` 再查版本。 |
| 撤销 | 桥在每个 RPC 前、浏览器轮询时及结果返回前重查 grant；桥进程退出丢弃会话和未决请求。授权撤销后新请求拒绝，已有写入可能形成既有 `operation-uncertain`，须人工核对，不自动重放。 |
| 日志 | 桥不记录请求正文、配对/会话密钥、资产内容或字段值；既有权限审计只记 ID、字段名、动作与结果。HTTP 错误只给固定错误码。 |

没有 Cookie 或宽泛 CORS。预检仅向固定来源返回 `POST` 与 `Authorization, Content-Type`；缺失/`null`/其他 `Origin` 均拒绝。`Host` 必须等于实际 `127.0.0.1:<端口>`，阻断通过其他域名指向 loopback 的 DNS rebinding 请求。配对密钥本身才是本地进程鉴别凭据；端口号或 `Origin` 单独都不是身份凭据。

## 威胁模型与剩余风险

| 威胁 | 处理或剩余风险 |
|---|---|
| 恶意网页、跨源请求或 `Origin: null` | 精确 Origin/Host、随机密钥、CORS 与非 Cookie 会话；无法仅靠探测端口配对。 |
| 同机恶意进程扫描端口、伪造 Origin | 进程可以伪造 HTTP 标头，但没有通过可信渠道交付的 256 位密钥仍不能配对。若它能读取启动器内存、浏览器进程或同账户私有文件，不能以本桥承诺隔离；应使用操作系统进程/账户权限。 |
| DNS rebinding | 仅监听数值 loopback，且校验实际 Host；不将 `localhost`、任意域名或网卡地址作为服务端 Host。 |
| 配对码泄露或浏览器 XSS | 配对码一次性、两分钟；会话不持久化、最多 15 分钟。XSS 能在已授权 Web 来源内读取会话并借用浏览器数据权限，Origin 无法防同源脚本；正式接线前须完成 CSP、外部 HTML 处理和浏览器安全审查。 |
| nonce 重放、延迟响应 | 每次 RPC 随机 ID、超时、完成即删除；重放/迟到拒绝。超时写入保留“结果不确定”语义，不能盲重试。 |
| 撤销与在途请求竞争 | 显式 Web 撤销先取消未提交写，再等待已进入存储的写完成后确认授权撤销；真实 RxDB 修改回调及重试复核取消与期限。已经交给存储的操作无法瞬时撤回，界面提示核对资料；响应丢失保留操作回执和人工核对。外部进程直接撤销 grant 与已进入浏览器存储的操作没有跨进程原子事务，不能宣称物理瞬时回滚。 |
| 泄漏未授权字段 | 浏览器投影后再出域，Node 拒绝额外字段；MCP 输出再次按授权裁剪。资产 `kind` 及基本时间仍会暴露给本地 Node 进程，需在 UI 说明。 |

## 验证与未完成

`packages/mcp/src/bridge.test.ts` 使用真实 loopback HTTP 验证来源/Host、一次配对、错误 Bearer、浏览器投影、隐藏字段保留、撤销、nonce 重放和超时；既有服务测试覆盖 MCP 工具协议、预览批准与操作幂等。`pnpm typecheck` 与包内 Vitest 是实现门槛。

2026-09-29：正式 React 设置页、独立 stdio 启动器和一次性文件配对已接入开发版。`tests/e2e/mcp-web.spec.ts` 用官方 SDK 客户端、真实浏览器 RxDB 和本机桥验证选定字段读取、逐次写批准、幂等、Origin/Host 拒绝、撤销及中英 390px；证据见 [08 交接](../08-项目进度交接.md)。

监督复核发现旧浏览器执行器在 `await store.get` 暂停时，即使显式撤销已经成功返回，恢复后仍可能进入 CAS。现增加本地写取消、存储中写等待、桥上 `/check-write` 与 RxDB 实际修改回调复核。确定性测试覆盖读暂停、CAS 等待、请求/会话到期、外部 grant 撤销和已落库但应答丢失；真实 RxDB 适配器验证两次回调关口以及桥内显式撤销。界面在撤销时已有存储中写操作的情况下给出核对提示。

**未完成**：正式跨平台打包与客户端配置分发、生产 HTTPS/PWA 到回环的浏览器限制验证、关页失败时的网络撤销确认、真实设备/用户资料验收和安全审计。源码开发版可手工配置，不等于普通用户入口已开放；不可开放无鉴权 localhost 全库接口。
