# ADR 0012：本机跨对象搜索与定位

日期：2026-09-30。状态：本机实现；最终浏览器与构建结果见项目交接顶部。

## 数据与范围

复用 RxDB 资产／历史／任务，以及 FileStore 的已确认收录元数据。搜索索引是内存中的派生投影，不持久化、不建立另一资产来源、不请求远端或 AI。实体数组随 RxDB rows 变化解析一次，输入查询不重新解析全库。

来源包括五类未删除资产、财务页实际可见的支出／充值／退款／余额／订阅续费历史、已确认 CSV／PDF 收录记录，以及没有影响分析／项目工作流／维护快照的普通任务。财务记录允许所属资产已软删，但不包含不存在或类型不合的资产历史。投递台账 Submission 不等于收录记录，本切片不加入。

空查询与非空查询都采用确定性顺序，最多15条；不标成“最近”。匹配沿用大小写无关的连续子串，使用名称、类型译名、位置、标签、日期、精确金额及对应显示字段；ID仅用于关联与跳转。

## 字段边界

FileStore liveQuery 只向 React 状态投影已确认候选的文件名、行号、类型、名称／网址、账单标题／金额／币种／日期／来源和定位 ID。PDF 原文、描述、私密备注和恢复日志不进入该 DTO。

PDF 提取原文也曾写入候选资产 description，故资产搜索额外按 PDF 候选资产 ID 和既有确定性 PDF ID 排除 description／longDescription。候选来源未加载或读取失败时，保守关闭资产描述字段。其它明确显示字段继续可搜，资产列表保留既有筛选实现。

资产 notes、流水 note、账单草稿 note、任务快照／凭据、附件引用、内部 ID 和日志不参与匹配。URL只保留 HTTP(S) 协议、主机和路径，剔除 userinfo、query、fragment；密码库深链及嵌入显示文本中的其它 scheme 深链不索引。此规则约束本机搜索投影，不宣称已经完成整个应用的安全或法律审查。

## 定位与 UI

结果沿现有顶栏浮层和设计变量显示实际名称、类型及摘要；沿用双语 key。点击显式关闭并清空查询。资产到现有详情；财务、收录与普通任务使用明确 hash 行 ID，目标页面等待记录渲染后滚动和聚焦。财务／任务的旧筛选仅在导航激活时解除；重复点击当前 hash 仍可定位，不在每次资料更新时强制清筛选。

收录同页定位可重新读取指定候选，合并目标行并保护正在保存的草稿；不以完整旧读取覆盖其它草稿。无效、缺失或删除的目标不写记录。

## 验证边界

纯模块单测覆盖跨来源、上限与顺序、删除、财务类型、PDF 描述旁路、加载失败、禁止字段、URL／深链和 typed target。正式浏览器验证双语／窄屏、同页定位及实际加密下载后干净恢复；具体次数和证据见[项目交接](../08-项目进度交接.md)。合成测试资料不代替真实用户全流程、真机、配额故障、生产同步和安全审查。
