# ADR 0014：统一选择控件与键盘表单合同

日期：2026-09-30。范围：正式 Web 的单选下拉；不改变资产模型、保存协议或同步来源。

## 决策与来源

复用项目既有 Button／Dialog 的 Radix 组合方式，引入精确依赖 `@radix-ui/react-select@2.3.7`，由上游处理焦点、键盘、typeahead、禁用项和碰撞定位。使用[官方 Select 文档](https://www.radix-ui.com/primitives/docs/components/select)中的 Root／Trigger／Value／Portal／Content／Viewport／Item 组合；没有复制业务源码或自行实现菜单键盘引擎。包内 MIT 正文及 npm 精确版本／安装路径记录在 NOTICE、SBOM 与许可证快照。安装树为607个包，原有31个缺包根正文项仍为26核实、5未解决。

统一组件位于 `apps/web/src/components/ui/select.tsx`，样式直接使用现有 paper、ink、line、yellow、danger、shadow 变量。替换14个现有模块中的43个选择控件；79个选项声明转换为 SelectOption。保留原字段值、禁用／busy 条件与业务校验；原134个非选择输入处理器不变。11个包裹标签补显式 htmlFor／id。现有容器 CSS 只保留尺寸和间距职责，菜单边框、颜色、阴影、焦点与错误统一由组件负责。

## 行为合同

- 控制值为字符串，回调用 `onValueChange(value)`，不伪造 React ChangeEvent。MCP 数字有效期只在界面边界 String／Number 转换，保存值仍为数字。
- SelectOption 支持数组／Fragment、禁用项和未声明 value 的纯文本货币选项。空选项仅在 Radix Item 内部使用避免碰撞的哨兵；Root 的空值仍是 `""`，回调还原空串。可清空关联／筛选，不把哨兵保存进资产。
- 保留上游 BubbleSelect 的表单桥接。空 required 触发原生 invalid，阻止提交；组件把焦点返回可见 trigger，显示既有双语错误，并合并 caller 的 aria-invalid／aria-describedby。合法选择或禁用后清除自身错误。没有写入或覆盖上游隐藏 select 的值。
- 所有可见 trigger 是 button／combobox；实际选项是 option。data-value 记录外部值供 DOM 读回；隐藏原生 select 只服务表单，验收不得操作它来冒充可见菜单成功。
- Portal 菜单高于 Dialog，按可用高度和视口留边定位。触发文本省略，选项长文本换行；移动触发器与选项最小44px、字号16px。Escape 关闭并返回焦点，方向键／Home／End／Enter 沿上游行为。
- 自动生成缺省 trigger id；已提供字段 id 保持不变。语言切换后标签改变，测试用相同 DOM id 读回值，避免把旧可访问名称当作丢失控件。

## 验证与界限

新增 `themed-select.spec.ts` 通过正式设置、账号创建、维护计划创建，覆盖中英390／1280、语言键盘选择、Escape／焦点、空关联清除／重新选择、required 阻止提交、长名称与菜单视口边界；不向页面注入源码或写 IDB。源版4项通过后还须在生成的同一固定包重复执行，并执行既有资产／审核／备份／同步回归。

126处旧测试交互迁移为实际点击可见 trigger／option。测试辅助器不得使用隐藏 select、派发事件、force 或固定 sleep。Radix 的 End 焦点更新异步，必须等实际 option 聚焦后按 Enter。菜单截图使用当前视口；全页截图可能调整视口并触发上游正常 resize 关闭，不能据此误判 Escape 不可用。
