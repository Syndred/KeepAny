# ADR 0001：阶段 0 存储基准与备份验证边界

日期：2026-09-28。状态：进行中；不得据此开放官方同步。

## 选择与可复现命令

KeepAny 本地记录层采用 RxDB 的 Dexie 存储适配器，二进制附件单独存入 Dexie。为检验这一组合，`tests/phase0/benchmark.ts` 在隔离数据库中分别对 RxDB + Dexie 和直接 Dexie 写入 100、1,000、10,000 件资产、等量关系及每百件一份 16 KiB 附件，测量批量写入、全量加载、索引查询、附件写入与浏览器配额估计。每组仅运行一次，结果不代表多设备性能区间或真实资料大小分布。

```bash
node scripts/phase0/run-benchmark.mjs
pnpm exec vitest run tests/phase0/backup-crypto.test.ts
node scripts/phase0/generate-license-inventory.mjs
```

基准需要本机已安装锁文件依赖及 Playwright Chromium。脚本启动本地 Vite，只连接 `127.0.0.1:4179`，完成后删除本次创建的 IndexedDB 数据库，结果存放 `tests/phase0/evidence/storage-benchmark.json`。不会主动写满浏览器配额；`QuotaExceededError` 应另在隔离浏览器配置中验证。浏览器清理告警与跨设备容量差异仍需要手工验收。

## 已核实

- `backup-crypto.test.ts` 用已安装的 Vitest 验证密码长度、错误密码、随机盐/IV、认证密文的头部、盐、IV、密文、标签单字节篡改与截断。测试数据是假资料；这些是本地加密备份容器验证，不是云同步密钥协议证明。
- 当前备份容器可以重复解密同一份合法密文，**没有重放检测**。云同步必须加入操作 id、版本/序列号与服务端持久化幂等证据；不能把 AES-GCM 的篡改检测当作重放检测。
- 2026-09-28 首次启动基准时，浏览器在导入两个版本的 Dexie 后抛出 `Two different versions of Dexie loaded in the same app: 4.4.6 and 4.4.2`。根包直接依赖原为 `dexie@4.4.6`，`rxdb@17.5.0` 安装树内依赖为 `dexie@4.4.2`。主实施会话将直接依赖对齐为 `4.4.2` 并更新锁文件后，基准全六组通过；首次失败保留为版本兼容性发现。
- `dependency-license-inventory.json` 从本次安装树执行 `pnpm licenses list --json` 生成，并逐包检查根目录的 `LICENSE` / `LICENCE` / `COPYING` 文件。它记录声明许可证、版本和文件存在性，以及锁文件 SHA-256。缺文件、传递包内单独声明、素材、字体、构建产物均需发布前复核；该清单不是完整 NOTICE 或最终 SBOM。

### 本机基准结果

环境：macOS 上的无头 Chromium 153.0.8010.12，浏览器报告 10 个逻辑线程、16 GiB 设备内存、约 3.0 GiB 本源配额，`navigator.storage.persisted()` 为 false。`IndexedDB`、Web Crypto 和 Storage Estimate 可用。精确环境与逐组 JSON 见 `tests/phase0/evidence/storage-benchmark.json`。

| 引擎 | 资产/关系/附件 | 写入 ms | 同页查询全部 ms | 关闭再打开查询全部 ms | 索引查询 ms | 附件写入 ms |
|---|---:|---:|---:|---:|---:|---:|
| RxDB + Dexie | 100/100/1 | 7.0 | 4.5 | 3.9 | 0.6 | 2.0 |
| RxDB + Dexie | 1,000/1,000/10 | 52.1 | 14.5 | 13.9 | 0.6 | 1.8 |
| RxDB + Dexie | 10,000/10,000/100 | 525.3 | 133.2 | 154.1 | 1.4 | 9.4 |
| Dexie | 100/100/1 | 3.8 | 0.9 | 0.8 | 0.3 | 0.3 |
| Dexie | 1,000/1,000/10 | 28.6 | 5.6 | 5.5 | 0.3 | 1.1 |
| Dexie | 10,000/10,000/100 | 283.8 | 48.8 | 46.7 | 3.6 | 7.5 |

附件每份 16 KiB。两引擎读回数量与索引命中、关闭数据库后重新打开读回数量均经过断言。浏览器配额估计的逐组用量差值受删除和异步回收影响，出现固定 221,184 字节与 0 字节，不能当作真实磁盘占用；Chromium 的 `performance.memory` 始终报告 10,000,000 字节，也不能当作可靠的峰值内存。需要补充操作系统磁盘读数、真实图片、移动设备和私密窗口测试。
