# ADR 0006：跨账号与跨远端显式迁移

日期：2026-09-29。状态：本机实现与验证中。

## 决定

一个浏览器资料仍只绑定一个服务、账号、工作区与同步范围。迁移不修改原资料的绑定，也不把原范围的密文、密钥、游标、持久队列或冲突状态复制给目标。用户先在来源浏览器资料完成同步并导出加密 `.ka1`；再在目标账号的独立浏览器资料中登录、选择目标工作区和密钥。目标先通过已有 `/sync/preflight` 身份与权限验证，并完整拉取已有的可解密目标资料，才允许预览来源归档。空工作区没有密文可证明输入的密钥正确，只能在本机固定其指纹并要求用户保管。归档可声明来源绑定；这是加密文件内的自声明信息，不是服务签名证明。旧归档没有该信息时，界面明确说明来源不能由文件验证。

迁移预览按稳定记录 ID 比较全部资产、关系、任务、分类、提交、历史、偏好和所引用原图。目标独有记录保留；同 ID 同内容跳过；同 ID 不同内容要求逐条选择来源或目标，不能设置统一默认。最终选择再次验证关系端点、图片引用和图片字节；相同图片 ID 但内容不同时拒绝合并。用户须先生成目标数据集的加密恢复备份、下载文件并重新选择该文件，通过解密、归档检查和摘要对比后才可确认合并。

本机合并先写可恢复日志，再写图片和记录。并发变化通过目标摘要和记录级条件写入拒绝；重启后未完成操作保留明确状态。同步开始前可撤销本次本机写入。开始向目标云端发送前再次预检目标身份；随后将日志改为“同步中”，这时可能已发生部分远端写入，不能声称可原子撤销。继续同步复用原有持久操作 ID、队列、冲突选择与幂等重试；全部待传和待拉取事项清空且本次同步成功后才清理迁移检查点。来源资料及两份 `.ka1` 恢复文件保留作人工恢复依据。

## 边界与验收

- 目标工作区已存在资料时，先拉取再比较；原浏览器资料直接改填另一服务或账号仍被数据集绑定拒绝。
- 已发生目标端部分写入后的“恢复”需要核对目标备份、云端已接受的操作与冲突，不能仅恢复本机文件后继续旧游标。界面只提供安全继续同步，不提供误导性的一键云端回滚。
- 本机自动化覆盖新记录、同 ID 冲突、历史和图片引用、错误目标、并发编辑、恢复日志、断网/丢应答重试；正式浏览器覆盖中英文目标身份、差异确认、恢复备份回读、回滚、继续同步与刷新。真实账号、远端对象桶、双设备和生产 HTTPS 另验。

这个决定沿用 [ADR 0004](0004-自部署多用户会话与本地数据集边界.md) 的单数据集绑定，以及已有 RxDB、`.ka1` 与加密同步实现；不开第二份资产状态源，不引用独立商业仓库的源代码。
