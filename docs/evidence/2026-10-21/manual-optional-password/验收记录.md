# 手动新增与编辑密码可留空

## 原因与修复

导入流程已有空密码支持，但手动编辑器仍有 input/textarea 的 required 属性，以及 saveEntry 对空字符串的二次拦截。移除这两层限制，标签改为「密码（可选）」／「Password (optional)」，提示允许第三方登录留空，删除无用的必填错误文案。普通密码标签与复制名称保留。KDBX 引擎原本允许条目密码为空，不改存储、主密码验证或生成密码功能。
