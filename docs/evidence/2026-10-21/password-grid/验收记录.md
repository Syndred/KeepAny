# 密码卡片多列预览与详情验收（2026-10-21）

## 设计与实现

用户确认「一行多个密码条目、账号／密码／备注／全部登录标识可查看完整、操作只用图标」的三列设计；设计参照保存为[已确认UI图](已确认UI图.png)。保留原应用的侧栏、字体、奶油底、墨蓝线条和硬阴影，复用 Button／TaskCard／TextLink、现有图标库与密码库服务；没有新增依赖或获取远端站点图标。

- 按容器宽度多列排布；1536×1024中英测试均显示三列六条常见内容，窄屏单列。内容更多时卡片自然增高，不裁切、不省略、不限制备注行数。
- 名称进入独立详情状态。账号、密码、登录标识、网址、备注均有就近复制；密码默认隐藏，可按需显示／隐藏，无密码条目明确标识。全部原值以现有KDBX为准。
- 卡片操作、工具栏为图标，44px点击区域，带可访问名称和悬停标题；卡片操作间16px、卡片间20px。新增同平台、编辑、历史、回收站以及导入／导出／锁库／改主密码功能保留。
- 详情支持浏览器返回、页面返回后原卡片焦点和位置、刷新后重新解锁；详情页不显示无关的外部引用区，外部引用仍保留在列表下方。
- 列表／详情切换与锁库不延续密码显示状态。复制请求失败迟到时，锁库／卸载后不再打开手动明文复制窗口。
