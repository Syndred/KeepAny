# 密码导入核对操作与主题排版验收（2026-10-21）

## 改动

- 名称、账号、其他登录标识、密码、备注与网址均可复制和粘贴；隐藏密码复制真实值，保留空格与 CRLF。普通条目编辑保留复制失败时的手动复制入口。
- 待核对候选、核对原文均可确认删除；只移除本次清单中的记录，不改写原始清单，不删除正式库条目。删除目标后，其他记录尚未应用的填写仍可按原目标找回，明确选择「作为新账号核对」；独立新建草稿不被覆盖。
- 顶部新增账号入口，自动选中新条目并聚焦名称；新增同平台账号沿用现有行为，手动新条目不再显示无关原文。

- 修复延迟粘贴调用旧别名数组的问题：读取期间删除前一别名或修改其他别名，不会复活或覆盖它们；本字段改变、关闭或锁定后旧请求失效。
