# 账号／密码库与资产入口合并验收

日期：2026-10-27。源码与固定包提交：`5c52efe`，基线：`6dafe59`。

## 完成范围

用户明确要求直接在原应用基础合并，保留原功能，不再做草图确认。本轮沿用正式 React 组件、按钮、选择器和主题变量，没有新依赖，没有采用原型 HTML 实现正式页面。

- 主导航合为「账号」「资产」；概览、待办、收录与备份、设置、回收站、自定义分类和跨类型收藏保持。
- 「账号」包含全部账号、密码管理和外部引用。解锁后按原显式关联 ID 显示密码条目数，尚未关联普通账号的密码条目也可直接打开；不会按服务名称或邮箱自动合并数据，不会把 KDBX 私密条目复制成普通资产。
- 账号详情可原地展开原密码库组件并按账号筛选。原密码生成／复制／编辑、多登录标识、同平台小号、历史、回收站、主密码修改、KDBX 与 KA1 导入导出、关联审核和 AI 智能导入入口保持。
- 「资产」汇总实物、项目、订阅和项目已有的域名；分类型原分类、标签、增删改、图片、外链、关系、待办、实物保修／借还／维护、项目工作流及费用账本保留。
- 实物展示按购买日期计算的已购天数及已知购入价；缺失和未来购买日期不冒充已购买。项目展示未删除且不属于账号影响清单的关联待办完成数，以及关联订阅和已记录支出；不将待办比例当成商业完成度。
- 域名与订阅显示剩余／逾期天数。域名直接回到原项目的域名记录，可继续原来的编辑、添加和删除；没有新增域名存储类型或迁移旧域名。
- 实物购入额、已记录支出、订阅月均预计分开；币种分别统计，金额使用现有整数小单位和 BigInt 格式化。关联重复关系与相同流水 ID 不重复累计，项目汇总不会再次加进全局支出。
- 资产详情的两个返回入口保留来源汇总、查询和滚动位置。旧 `/assets/project`、`/assets/item`、`/assets/subscription`、`/assets/account`、`/assets/vault`、`/finance` 及详情链接继续可用。
- 旧导航顺序／隐藏偏好只在读取时投影到新分组；新分组仍可排序和隐藏，至少保留一个资料分组。跨类型收藏中的五类对象保持原 ID。

## 数据边界与自审

核心仍从原 RxDB 读取；密码仍只写原独立 KDBX。未修改 schema/title、已有存储键、KDBX 字段、KA1 格式、同步／绑定／MCP 协议、旧环境变量、PWA 身份与 4180 地址。新加入的会话存储只记录普通界面偏好和汇总返回位置。

合并后的账号本页搜索在解锁时可能匹配 KDBX 私密元数据，因此该状态下的查询与返回查询不落会话存储；锁定后恢复原普通查询并隐藏密码条目及计数。没有把密码库加入顶栏全局搜索、普通 AI、MCP 或常规同步，没有调用真实模型或读取用户密码。

自审补齐：历史项目可能尚无 `projectDomains`，统计和渲染均按空数组兼容；实物没有分类时不显示空白标签。密码详情使用现有完整组件；嵌入后用二级标题，保留一个页面主标题。汇总卡片间距 20／24px，导航项 12px，按钮和状态栏保留独立间距；中英文窄屏检查无横向溢出。

- 原密码恢复测试最后仍点击已合并的侧栏「密码库」，因此超时；改为「账号 → 密码管理」后，同一完整密码／备份断言在源码和固定包均通过。

- 整理页首次保存时读到空名称；补充填写后及保存前的字段回读后通过，没有修改产品保存逻辑。首次为空的原因没有单独证实，未虚构已修复产品原因。
- 合并后的界面文字／路由相关旧测试同步到新入口；没有删除原 KDBX、金额、身份、回收站或备份断言。
