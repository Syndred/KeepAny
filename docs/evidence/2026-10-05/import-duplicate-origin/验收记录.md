# 新增同平台账号的重复提示修复

旧正式包已用假数据复现：新增的账号与本次清单另一条相同，却显示“密码库中已有相同条目”。判断原本包含平台（网址或名称）、主账号、密码，并非只比较平台名；错误在于没有区分清单内重复与库内重复，也没有定位对应条目的入口。

修复由核心预览返回清单重复来源行号，UI在过滤不完整条目后重新映射索引，显示“本次清单中已有同平台、同账号且密码相同的条目”，并提供“查看清单中的条目”。跳转到已有候选，不覆盖任一草稿。库内重复仍保留原提示；同平台不同账号，即使密码相同，也正常独立新增。
