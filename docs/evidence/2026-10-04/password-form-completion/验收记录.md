## 实际操作结果

| 操作／状态 | 验证结果 |
| --- | --- |
| 未归属原文→填写名称、账号、密码→加入待导入→勾选确认 | 真正写入独立KDBX；缺项先成为待补卡，完整前不能勾选；邮箱／App不需网址 |
| 表单新建／补充切换、目标切换、收起／再展开 | 各自填写保留；未修改已有目标时不能应用；未触碰字段采用目标最新值，不覆盖并发修改 |
| 查看原文、把原文加入备注、补充已有候选 | 原文默认遮罩；只有另点加入备注才保留原文，不猜归属；只改变所选目标 |
| 返回其他输入方式、文件失败、AI失败、无效映射、再返回核对 | 旧结果、修改、勾选及未提交表单保留；手工补填不重跑AI |
| 手工映射追加一部分，另一部分尚未完成 | 仅消费成功块／明确忽略的行；原片段表单与其余警告保留；不覆盖AI候选与来源 |
| 完整条目先入库，只剩片段 | 核对页和未提交表单保留，继续新建或明确补充本批已经保存的目标 |
| 继续补充已经保存的对象／同密码对象加备注 | 明确选择更新后保存同一ID及历史；不重复新建，不静默丢弃补充内容 |
| 取消、关闭、锁定、迟回／修订冲突 | 保持既有取消与失效边界，关闭／锁库／刷新清除导入临时秘密 |
| 最终保存、导出、解密及刷新解锁 | 主流程逐项回读5条合成KDBX记录；新增更新场景回读同ID、最终字段和历史 |
