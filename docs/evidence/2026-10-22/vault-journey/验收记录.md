# 密码库导入、账号分类与关联图验收（2026-10-22）

## 本轮问题与修复

- 旧导入账号没有分类；相同邮箱／手机号以业务账号随机作为中心，重复选择不同子集还会增加错误连线。现在按登录标识建立独立邮箱／手机身份，优先复用已有身份，服务账号指向实际身份。邮箱用户名不等于邮箱类账号，普通数字不猜成手机号，国内手机号与 +86 写法归一。
- 关联审核可以调整分类；已有人工分类保留，无法识别的服务归入其他。旧账号公开资料可更新；仅清理能够证明来自旧规则、且本次已审核替换的自动连线，人工修改与未选资料保留。关联冲突条目单独提示，其余条目仍可操作。
- 关联图采用项目已有 React Flow 与成熟 Dagre 布局，默认直接关联，可切换完整关系；保留方向、关系状态与间接路径，搜索突出匹配，不删除中间节点。增加定位当前／查看全图，初始视图保持当前账号可读；卡片之间及不同目标的连线留出间距。
- 实际重走导入时发现空密码条目的逗号备注会误判，已修复；密码库“显示全部”同步清除地址筛选，刷新后不再回到单条。手机工具栏采用四加四排列，按钮点击区域不小于 44px。
- 并发审查发现两个批次新增同一稳定 ID 时，失败批次可能回滚另一批已保存资料。现在复用既有队列及数据库级 Web Lock，将两个批量入口与启动日志恢复串行处理；保留故障回滚及重试合同。双仓库同 ID、两入口混用与启动等待锁均有回归。
- 复用现有组件、主题与中英文文案键。没有读取主密码值，没有调用真实 AI，没有向模型发送原密码库。
