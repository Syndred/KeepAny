# 删除后密码账号重新关联：原因、修复与验收

## 原因

原 Chrome 4180 通过界面复现：密码条目的旧关联显示「资产已不存在」，同名普通账号仍在回收站。KDBX 保留原账号 ID，普通资料保留删除标记；旧审核为了防止误恢复而阻止导入，但只输出混合警告，没有具体原因或处理入口。仅删除连线时，稳定 ID 去重还会无声跳过重新勾选的关系。

## 完成

- 逐项区分普通账号与邮箱／手机身份的删除、重复、变更问题；异常类型之外的加载错误不再伪装成账号冲突。
- 原审核列表内提供恢复账号、明确选择已有账号。恢复复用数据库现有回收站机制；换绑只移除明确审核的旧账号关联，保留其他资产关联及 KDBX 内容和草稿。保存前显示公开资料更新及原资料供核对。
- 有效新关联或已保存的身份关系可继续复用，不因旧稳定 ID 留在回收站而再次被错误阻止。
- 已删除关系保留同一 ID，默认不勾选。主动勾选并保存才恢复，未勾选关系继续保持删除。审核后的新删除／变更会要求重新审核；数据库恢复使用 CAS 并复核端点。
- 复用原左右审核布局及 Select／Button，问题卡置于账号滚动区域，支持同一搜索。44px 操作目标，卡内12px、卡间16px；处理后保留其他选择、分类、线索并恢复键盘焦点。中英文均检查。
