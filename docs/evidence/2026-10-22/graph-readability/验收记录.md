# 多账号汇入同一身份的关系图修复（2026-10-22）

## 用户反馈与原因

上一轮证明了关系保存与节点范围，但对真实密集图的文字遮挡验收不足。用户截图中多个服务汇入同一邮箱，每条线常驻重复标注「登录邮箱」，标签处于共用竖线中段；后绘制的其他线会盖住前一条线的文字背景。两条不同用途被拼成一段文字后，重叠更明显。

这不等于应删除关系数据。同一来源到同一目标可以同时有登录邮箱、第三方登录或找回用途，须分别保留。此次只修展示和选择交互，没有因文字重复而删除关系。

## 完成

- 复用 React Flow 的 BaseEdge、Panel、受控选择与键盘能力。账号图默认只画线和方向箭头；点选一条线后加粗置顶，其他线淡化，单份实底说明显示来源、目标、不同用途和核验状态。相同用途仅在说明中去重，不改底层记录。
- 鼠标和 Tab + Enter／空格均可单选；关闭、点击空白、切换范围或账号后清空。图为只读展示，Backspace／Delete 不删除记录；实际删除仍走原列表确认流程。保持原有布局、直接／完整关系、搜索、缩放、定位和非账号图行为。
- 手动从空白账号表单验收时发现「其他」分类缺失。原因是表单复制的三分类与导入／列表四分类漂移；表单现复用同一份内置分类，不另建状态源。
- 首轮新用例查出关闭按钮实际为 36px，被通用 icon 尺寸规则覆盖。移除冲突尺寸变体，最终实测 44 × 44px；没有降低断言。
