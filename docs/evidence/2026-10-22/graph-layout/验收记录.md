# 双侧账号族谱验收（2026-10-22）

用户批准当前账号居中、关联账号均衡放在左右两侧的草图。此前单侧长列导致全图缩小后字号过小，重复用途文字又压在线上。本轮保留已修复的按需关系说明，重点替换布局和阅读导航。

## 实现与自审

- 复用 ELK 0.12.0 和 React Flow。按唯一分支权重分配两侧，密集图有紧凑卡片候选；正交路径由 ELK 提供，逐候选检查卡片不相交、路径避开其他卡片、端点正确、数值有限。保留实际关系方向；互逆方向用不同端口，循环及跨侧关系不删边。
- 当前账号优先居中，以清晰字号打开。名称基础14px、标识12px；可读初始适配阈值为11/12，无法同时完整可读时保留阅读倍率并支持平移。查看全图是结构总览，不用总览小字代替阅读验收。
- 扩大画布复用现有 Dialog；关闭恢复范围、搜索、已选连线、阅读账号和倍率，以及扩大按钮焦点。布局异步请求丢弃过时结果；搜索或选边不触发重排。原始账号和关系均只读，不读取密码库、主密码或发送 AI。
- 缩放、适应视图、小地图放在画布上方的独立区域。小地图按真实卡片尺寸绘制，可点击或拖动定位。操作目标44px，按钮、画布和导航留独立间距。中英文文案一致。
- 核心和 UI 均经其他代理只读复审；无明确 P1/P2 遗留。全部功能结论仍以同一个最终固定包的浏览器检查为准。
