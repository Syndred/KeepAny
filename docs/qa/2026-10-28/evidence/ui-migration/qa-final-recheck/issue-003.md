# ISSUE-003：同排卡片底边不齐

在 03c676734e3e 便携包 /assets 卡片模式、2220×1321 下，首排底边分别为 655.6875、555.6875、661.6875、581.6875、632.1875、605.1875、559.6875。probe-014 与原命令重放 probe-016 一致，截图 assets-cards-zh-2220.png 已查看。

根因：三类列表 grid 使用 align-items:start，内容容器按天然高度。仅限制宽度不能保证同排对齐。

修复：卡片视图 grid stretch，项目/实物内容容器占满可用高度，状态/操作尾部 margin-top:auto。紧凑列表不受卡片规则影响，单列不强制全页等高。

红测：ui-density 的真实同排几何断言在 zh-CN/1280 失败，见 ../card-align-red.log。绿测和新包复验随后另存，本报告保留发现时输入与失败，不标最终通过。
