# 05 UIUX与中英文规范

## 视觉基准

设计参考位于design/keepany-ui-reference.html。保留奶油背景、深蓝描边、多色卡片和紧凑布局；以组件重建，避免继续追加覆盖样式。原型中文工作名不是最终品牌文案，正式应用统一KeepAny。

- 间距token：4/8/12/16/24/32px；常规卡片内边距16，卡片间16，字段组间12，标签间8。
- 字号token：辅助12、标签13、正文14–16、小标题18、页面24–28；正文行高1.5。移动端输入至少16px。
- 不设无内容依据的固定大高度；同排卡片内容少时顶部对齐。订阅桌面两列，资料字段左右组合，窄屏自然一列。
- 字体优先系统中英字体，数字tabular-nums；不得因换语言改成溢出或裁切。
- 点击目标至少24px，移动端主要操作尽量44px；键盘焦点清楚，拖动有键盘/排序替代。

## 已确定交互，不能回退

| 页面 | 要求 |
|---|---|
| 导航 | 概览下方待办；侧栏手柄拖动排序；AI独立右上角入口；收录用+ |
| 分类 | 项目含网站/仓库/工具，账号含邮箱/手机/自媒体；可自定义；分类后+，管理居右同一行，窄屏可横滑 |
| 详情 | 左上返回直接回所属列表并恢复筛选和滚动，不逐次退关系图历史 |
| 关系图 | 点击节点即切换中心；有方向/类型提示；不出现“以此为中心”等冗余按钮；邻居多时可筛选 |
| 项目 | 资料与维护提醒横排，外链占下一整行；投递素材/长内容折叠；不扩无关字段 |
| 外链 | 名称统一“外链”；真正table或同一grid列轨道；表头/单元格一致对齐；窄屏横滑或有标签的列表 |
| 账号 | 资料可编辑、紧凑卡片/标签呈现；关系和资料分开；重要状态有文字与颜色 |
| 实物 | 图片在资产卡内；位置在卡片body；状态与操作不压字，不用空白凑高 |
| 订阅 | 金额、周期、关联标签、到期状态分组；待续费底栏独立间距 |
| 收录/备份 | 两卡不强制等高；按模式显示对应输入；真实恢复状态，不放无作用按钮 |

## 动效

复用Motion：hover 120–160ms、展开/切页180–240ms；列表布局变化可用layout，拖动不和hover transform冲突。遵守prefers-reduced-motion；保存/失败/加载有反馈，不用无限动画掩盖失败。只为定位和状态变化增加动效。

## 状态矩阵

所有页面覆盖：有数据、空、加载、离线、错误、无权限；列表另有筛选无结果。按钮覆盖default/hover/focus/pressed/disabled/loading/success/error。编辑覆盖未改动/脏值/校验错误/保存失败/取消；破坏操作可撤销或确认。禁用不能只变浅到看不见，错误贴近字段且可被读屏读取。

## 仅两种语言

- locales/zh-CN与locales/en一一对应，CI检查缺key。默认系统语言匹配，否则英语；设置持久化。
- 中文功能名：项目、账号、订阅、实物、待办、外链；英文：Projects、Accounts、Subscriptions、Items、Tasks、Backlinks。
- 不拼接翻译片段；数量用复数规则，日期/金额用Intl；界面语言不自动改变用户币种或内容。
- 自定义分类/名称保留用户原文，不偷偷翻译资产资料。
- 初期帮助、错误、通知、导出字段说明、隐私授权同样中英，不只翻译导航。

## 视觉验收

360/390/768/1280/1440宽度，中英各检查。逐页和逐弹窗截图，长标题/长邮箱/英文撑宽/零值/大金额/缺图/100标签作为边界样本。检查裁切、横向溢出、表头错位、无意义空白、焦点、拖动和动画降级。旧原型回归记录不替代正式React应用浏览器验收。
