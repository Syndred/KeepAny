## 已完成的本地实现

- 资产、关系、分类、待办及历史统一写入 RxDB + Dexie；TanStack Query 不充当第二资产源。CSV 批次有持久日志，失败可回滚；墓碑/恢复保留记录。图片确认后写入，损坏文件阻止确认，离开引用时清理孤儿文件；备份包含被引用图片。
- 备份先本机导出归档，再用密码加密；恢复先预检后确认。`tests/e2e/local-core.spec.ts` 在 Chromium 中按正式 UI 创建项目、账号、订阅、连接和待办，点击“保存备份文件”触发浏览器下载，取实际 `.ka1` 文件，打开全新浏览器上下文恢复，刷新后逐项读回。此结果比此前开发接口取 blob 的证据更强；仍未在 Ego 原生下载管理器或真实移动设备手工取回文件。
- Web 拆为独立路由和按需详情/工作流 chunk。生产构建入口约 386.70 kB（gzip 125.94 kB），原单包约 1,072.91 kB（gzip 341.72 kB）；PWA 总预缓存仍约 1,097 KiB。示例数据改为一个可恢复批次，避免分条写入留下半套示例。
- 服务端使用工作区权限、期望版本、持久操作 ID 和墓碑。拉取合同现在返回原始 `operationId`，003 SQL 迁移按旧 accepted 操作回填；JSON 状态也兼容回填。真实 PostgreSQL 17.11 + Hono HTTP 本机双客户端测试覆盖同版本冲突、成功/失败重放、墓碑不复活、分页、跨工作区拒绝、加密信封与经本机 S3 HTTP mock 的密文附件读回。另构建独立 Compose，启动、健康检查、push/pull、401 和容器重启读回已过；测试机器 Docker daemon 后续无响应，003 迁移和最终资源清理微调没有再次实库复跑。
- 绑定消费端固定 issuer/JWKS、RS256、`aud=keepany-binding`、签名、`kid`、精确 `sub`/`bindingId`、实例摘要及 60 秒时限。设备 P-256 私钥不可导出并保存在本机 IndexedDB，刷新使用 DPoP 证明和持久随机请求 ID 的短时恢复；本地测试覆盖验签、切换确认、原子持久化与重试。设置页仅在配置固定 issuer/本机桥时显示只读绑定入口；桥只转发四个绑定 POST 与 JWKS GET，保留商业 issuer 用于票据与 DPoP 验证。跨进程合成 Plus 账号的账号页面批准、状态 `active`、只读令牌续期、账号页面撤销、本地状态 `revoked` 与清凭据均已在隔离 Chromium 跑通。同步服务 `bound` 模式另验 `aud=keepany-sync-bound`、设备指纹、请求证明和读写范围；`self-host` 静态 Bearer 仅在显式模式下使用。
- MCP 独立 Node 进程与浏览器之间有受作用域限制的 loopback 桥原型；配对码/会话/请求 nonce、Origin/Host、字段投影、隐藏字段保留和撤销重查见 `docs/adr/0002-mcp-bridge.md`。它尚未接到正式 Web UI，不能被描述为用户现可用。

## 阻塞与边界

- KeepAnyAdm 本机合成账号联调时工作树仍有未提交改动，需在固定已提交版本和真实受控账号上重跑。浏览器受限回环桥没有可信安装/启动器、端口发现或生产同源安全配置；本机续期凭据仍是敏感存储。商业挑战票据不能当同步 Bearer，已签发访问令牌也没有被 Web 资产同步运行器消费。
- `bound` 模式使用运营方预置映射，缺商业 `/state` 实时核验、动态撤销传播和多实例共享 DPoP 重放存储；已签发访问令牌在剩余最多 60 秒内可能离线有效。未提供生产 issuer、JWKS、R2、PostgreSQL、HTTPS/账号凭据，因此不部署官方云服务。
- Web 没有按工作区隔离的持久待推送队列、确认后基线与游标、冲突明细/解决界面或设备密钥配对。003 迁移补齐拉取变更的 `operationId`，但 AEAD 信封仍将客户端预先封装的 `sequence` 与服务端提交时才分配的全局序号混用，跨记录并发下无法可靠核对；不能把现有协议测试当作正式加密同步已验收。
- 本机双客户端不等于两台物理设备；本机 S3 HTTP mock 不等于真实 R2/S3。服务端无法证明上传内容已加密，哈希不代替客户端 AEAD 认证。MCP 桥仍需可信启动器、正式 Web UI 和真实浏览器 CORS/进程联调。
- 原生 Ego UI 控制被系统采集错误阻断；没有绕过浏览器安全界面。真实设备、用户调研、生产数据、完整许可证兼容性及法律审查均未完成。
