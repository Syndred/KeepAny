# 08 项目进度交接

更新：2026-09-28。本文记录 KeepAny **开源核心**的本机会话；独立商业仓库 KeepAnyAdm 由另一条会话负责，不能把其进度或源码计入本仓库。

## 已完成

- 建立 pnpm 锁版本工作区，正式 React/Vite/TypeScript 应用和 zh-CN/en 文案。已有项目、账号、订阅、实物、密码库引用、分类排序、搜索、关系图、待办、回收站、外链台账、图片附件、URL/CSV 预览收录和本机加密备份界面。
- 核心资产由 RxDB + Dexie 本地仓库管理；浏览器重开后记录仍在。CSV 使用本地批次日志，失败可回滚；删除记录使用墓碑与显式恢复。图片写入失败或从资产移除后会尝试清理无引用 blob，墓碑/恢复日志仍引用的图片受到保护；备份只打包实际引用的图片。Vite 热更新复用本机数据库实例，避免重复开启同名 RxDB。
- 阶段 0 基准记录 100/1,000/10,000 资产和关系及附件的读写数据。加密备份有密码错误、认证标签篡改、截断等测试；加密同步信封原型有设备加入、恢复、撤销后轮换和浏览器烟测。详见 `docs/adr/0001-阶段0存储与备份验证.md` 与 `packages/crypto/README.md`。
- ExternalLink 映射和 S3/WebDAV 加密备份传输完成假数据与模拟远端读回；项目外链状态须保存提交日期与证据，标记“已收录”须填写证据链接。没有真实外链提交或索引验证。
- Hono/PostgreSQL 同步服务基础具有工作区权限、事务 push/pull、幂等、版本冲突、墓碑及迁移；密文附件接口以工作区权限核查、SHA-256 读回和同 ID 重试为边界，本地 S3 兼容 HTTP mock 已跑通签名 PUT/GET。Docker Compose 可解析。官方服务尚未上线。
- BYOK/自托管模型对话界面仅发送用户选中的资产摘要；API Key 保留在当前弹窗状态，未写入本地仓库。
- MCP 子包以官方 SDK v2 的 stdio 工具协议实现本机作用域授权、撤销、只读投影、写入预览与外部批准、幂等和审计；已做官方 client/server InMemoryTransport 联调。独立 Node 进程尚无可信浏览器桥接，不能读取用户浏览器 RxDB。

## 验证证据

- 本机执行 `pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm lint`；最终结果见本文末尾“本轮最终校验”。服务 SSR 构建与 Compose `config -q` 单独执行。
- 阶段 0：Chromium 153 无头基准的 10,000 组 RxDB + Dexie 写入 456.4 ms、重开读取 142.9 ms、浏览器估计配额增量 16,482,304 字节；均为单次测量，不是性能承诺。精确 JSON 在 `tests/phase0/evidence/storage-benchmark.json`。
- 本机浏览器打开正式应用，中文项目新建、详情、刷新后回读成功；另在隔离浏览器验证英文项目新建、外链证据门槛、已收录状态与日期刷新回读。CSV 两条测试行中，一条已存在项目显示“重复”并禁选，仅另一条导入，刷新后项目列表仍有该记录。图片先预览后确认，有效 PNG 保存后刷新读回且自然宽度为 1；损坏 PNG 显示错误并禁用确认，移除后图片卡片消失。390 px 手机视口验收过中英布局和抽屉；修复顶部横向溢出后 `scrollWidth=innerWidth=390`。热更新修复后未见新页面运行错误，之前的 DB8 错误仍留在历史控制台日志中。
- 本机浏览器以测试资料生成 1,542 字节加密备份，因隔离浏览器未交付下载事件，使用同来源开发接口读取 blob 并保存测试文件。全新 `127.0.0.1:3102` 浏览器来源先确认项目列表为空，再通过正式恢复界面输入测试密码、预览并确认 4 条记录；刷新后两个项目仍在，项目图片 `naturalWidth=1`、外链状态和依据均读回。此证据覆盖加密文件内容与跨来源恢复，不覆盖普通用户点击“保存备份文件”后的文件落盘。
- 密码、附件、同步和许可证的证据以测试/ADR/源文件为准，不能把模拟器通过换算成真实设备、真实云存储或生产安全验收。

## 未完成与阻塞

- 阶段 0：本轮 Chromium 没有应用 1 MiB 配额覆盖，`QuotaExceededError` 未复现；真实磁盘、私密窗口、移动设备与浏览器清理后恢复尚未实测。已按最终锁文件重生成 563 个包版本的许可证清单，27 个安装包根目录缺许可证文本；清单不是完整 NOTICE/SBOM。
- 阶段 1：缺少真实用户的“项目→账号→订阅→待办→备份恢复”完整手工走查、所有弹窗的双语截图及移动设备测试。PWA 构建有约 1.07 MB 的主 JS 包警告，需做按路由拆包与低端设备加载验收。备份现有独立“保存备份文件”链接，但隔离浏览器仍未交付普通下载文件；仅完成开发接口取出测试文件后的空白来源恢复，尚缺真实用户保存/取回/恢复走查。
- 阶段 2：ExternalLink 仅 fixture 映射，未接真实资料/授权；S3/WebDAV 仅模拟端点，未使用真实凭据或远端桶；URL 收录、复杂 CSV 错误恢复与多图片逐项确认仍缺完整浏览器走查。
- 阶段 3：可信设备公钥配对、恢复凭据服务端核验、撤销/epoch 持久检查、冲突界面、大附件分块、真实双设备联调、安全审计、真实 R2/S3 及 Docker/PostgreSQL 实际部署尚未完成。服务端无法证明附件真的由客户端加密，SHA-256 也不能代替 AEAD 认证；不能开放官方同步。
- 阶段 4：BYOK 只做最小只读问答，未有费用测量；MCP 缺 Web 授权/批准界面与可信浏览器桥接，签名权益等仍在开发/审计。商业官网/支付/运营后台属于独立 KeepAnyAdm 仓库。不能宣称商业服务已上线。
