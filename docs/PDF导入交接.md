# PDF 文本收录交接

更新：2026-09-30。

## 完成

- 收录新增 PDF 文档入口，使用官方 `pdfjs-dist@6.3.289` 本机 worker 读取文字，不上传文件。整份文件仅生成一条候选，原文独立保留，名称与描述可编辑；用户必须明确选择资料类型才能确认入库。
- 复用既有候选暂存与 RxDB 资产写入流程，SHA-256 文件内容决定稳定候选及资产 ID；刷新、重传、改文件名继续原确认或忽略状态。未确认不创建资产，不推断金额、日期、周期，不写财务流水。
- 限制 10 MB、20 页、2 万字符及 30 秒读取时间；任一空白/无文字页整份拒绝，超限不截断。损坏及密码保护文档提示未生成候选。原文件不作为附件保存，用户确认的是提取文字资料。
- 候选确认先等待编辑写入，再获取决策锁并重读记录，避免编辑与确认争用同一锁导致等待循环。

## 依赖与来源

- 使用 npm 官方发行包，不复制修改上游源码；许可证 Apache-2.0，正文指纹已纳入 NOTICE/SBOM/依赖快照。官方接口参考：https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html 。
- 锁定版本 6.3.289 的 API 已无 `isEvalSupported`；构建源码检索未发现动态 `new Function(...)` 或 `eval(...)` 调用，未通过类型断言传入已移除选项。
- 当前安装树使用恢复 store，安装：`pnpm add -w pdfjs-dist --save-exact --store-dir /private/tmp/keepany-pnpm-recovery`。许可生成脚本增加可选 `KEEPANY_PNPM_STORE`，使用 pnpm 官方 `--config.store-dir` 参数；不修改用户全局设置。生成结果592个包版本，31项缺包根许可证正文，正式发布许可证总门槛仍未关闭。

## 未完成与边界

- 这是文档文字收录，不是账单结构化解析、交易自动入账或 OCR。未覆盖所有银行版式、缺失字符映射、外置 CMap、复杂表格、多栏阅读顺序、物理手机、加密PDF fixture、30秒超时与20页上限浏览器负例；用户必须核对提取文字。扫描件和包含无文字页的混合文档需人工整理。
- 候选、原文、手动修改与确认／忽略状态已纳入加密 `.ka1`，可在干净浏览器恢复后继续审核；旧候选库非破坏迁入同一文件仓库。它们只存当前浏览器，不参与云同步；原 PDF 文件仍不保存。实现与恢复／合并边界见 [ADR 0009](adr/0009-订阅关联恢复与收录审核备份.md)。
- 新图与流程不代表全部交互或设计稿已验收；Ego 原生、用户原 Chrome 和生产包验证由主任务记录。
