# UI 原稿对照与修复表（2026-09-29）

基准：`design/keepany-ui-reference.html` 在 1280px、UTF-8 静态服务下的实际渲染；正式应用用相同视口、同类真实结构资料对照。原稿数据仅作为版式示意，不能写入用户库。

| 区域 | 原稿最终可见结构与点击 | 当前 React 偏差 | 修复目标 |
| --- | --- | --- | --- |
| 概览 | 黄色几何 Hero、快速收录条、三指标、待处理与账号关系提醒双卡、我的项目卡 | 通用标题、月均费用、待续费和最近更新；信息层级不符 | 复建原稿层级，指标、提醒和项目关系由现有本地记录派生；空态仍保留卡片 |
| 侧栏 | 品牌、个人工作区、工作空间分区、可排序导航、自定义分类、个人信息底部 | 每行常态上下箭头、缺工作区和分类段 | 常态以导航为主，排序动作进入管理态；分类直达对应列表 |
| 顶栏 | 右侧搜索、待办铃铛、AI 菜单、+ 收录；AI 菜单先显示“检查变更影响／助手授权” | 搜索在左、无铃铛、AI 直接打开模型配置表单 | 恢复外观与两段式入口；每项走现有真实业务路径 |
| 项目与账号 | 分类/管理同排、卡片列表、整页详情、节点切中心与回所属列表 | 通用列表和详情密度/布局偏离 | 按代表资料逐页对照，保留已有编辑、关系、外链及回位功能 |
| 订阅与实物 | 紧凑卡片、金额/周期/状态及图片/位置按原稿分组 | 通用资料行 | 按资产种类还原分组，不写示例值 |
| 收录与备份 | 双卡、模式输入随选择变化、状态明确 | 堆叠技术表单与通用空态 | 保留真实预览/备份/恢复，按模式组织 |
| 设置与授权 | 基础设置优先，助手授权等能力由次级入口进入 | 默认堆叠 MCP、令牌、密钥和迁移 | 基础设置清楚可用，进阶功能仍可进入且权限边界不变 |

验收以相同视口截图和逐项点击为证据；功能测试通过不等于原稿一致。
