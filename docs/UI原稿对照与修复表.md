# UI 原稿对照与修复表（2026-09-29）

基准为 `design/keepany-ui-reference.html` 的可见结构和点击流程。原稿内的 Mori 等资料只用于理解交互，正式应用的项目、关系、账单和处理结果均须来自用户本机 RxDB 记录；产品页面不能出现开发验收说明。

| 区域 | 原稿可见操作 | 正式应用实现与核对点 | 状态 |
| --- | --- | --- | --- |
| 概览与顶栏 | 快速收录、项目卡、搜索、待办、AI 入口、返回 | 入口指向正式路由；顶栏返回由实际页面路径决定；指标与提醒来自本机记录。 | 已接入，旧界面矩阵仅作版式证据。 |
| 侧栏 | 入口排序、显隐、自定义分类与分类详情 | 排序和显隐写入本机偏好；概览及最后一个资产入口不可隐藏。跨类型集合可增删改成员、刷新回读并打开资产；各资产类型原有分类保留。 | 已接入，侧栏与集合定向回归。 |
| 项目与账号列表 | 分类管理、选择成员、卡片与关系导航 | 分类成员直接更新现有资产类别；关系节点和详情跳转到真实资产；不插入原稿示例。 | 已接入，分类成员定向回归。 |
| 项目详情 | 资料与封面、外链核验、域名成本、关联订阅、投递素材 | 域名现有领域字段可保存注册商、到期、年费和自动续费记录；费用仅按已记录金额估算，多币种分列。外链状态和素材仍走原记录与附件。 | 已接入，先前“无域名模型”结论已失效。 |
| 更新站点资料 | 影响预览、生成处理计划、逐项留证、阻碍与汇总 | 由当前项目、外链、关系和域名生成 RxDB 待办；建议资料与当时来源留快照；完成、阻碍和不适用均需依据。 | 已接入，领域与浏览器定向回归。 |
| 关闭与交接 | 检查备份、账号、订阅、域名和外链，最后确认处理记录 | 清单由真实关联记录生成；未解决项阻止最终决定。本机归档需显式确认且写前重读，不代表外部服务已经关闭。回收站删除不能代替交接。 | 已接入，领域与浏览器定向回归。 |
| 更换手机号／账号影响 | 查看账号关系、生成逐关系核查清单、记录核查结果 | 复用既有账号关系快照与待办流程；关系发生变化时提示重新核对，不替用户执行外部换绑。 | 已有功能；不能把清单完成当成外部换绑成功。 |
| 订阅与账单 | “记一笔”、计划／实付／余额分开、流水筛选 | 手动支出、充值、退款和余额观察写入 RxDB 历史，关联真实订阅或账号；预计月费、已记录支出和最新余额按币种分列，并可按类型、资产、付款来源筛选。续费历史计入已记录支出，同笔重复录入会重复计入，不能把预计续费当已付。 | 已接入，领域与浏览器定向回归。 |
| 实物档案 | 购入价、启用时间、状态日期、维修与转卖记录 | 购入价区分未记录与明确 0 元，旧非零金额仍可见；启用日、保修状态及五种物品状态保存于资产。状态变更写入同一 RxDB 原子历史，留日期与备注；维修仍用既有维护记录。“已转卖”仅为本机状态，不证明真实出售。 | 已接入，领域、仓库与中英浏览器定向回归。 |
| 待办 | 新建计划、关联资产、重复规则、提前提醒、完成、延期 7 天与跳过 | 维护计划绑定真实资产，单次／固定间隔／完成后间隔按纯日期推进；提前提醒和计划金额只作预计。完成、延期和跳过都需记录日期与原因，延期只调整本次到期日、不漂移固定间隔锚点；同一 RxDB 待办保留处理历史。 | 已接入，领域与浏览器定向回归。 |
| 收录 | URL／图片／CSV／手动，候选改名、确认导入 | URL/CSV 预览中可修改名称，写前再次校验和验重，仍使用现有批量保存；图片只保留原图，不声称 OCR。 | 已接入，定向回归。 |
| 导入审核示例 | PDF 账单及 CSV 候选“确认／忽略” | 正式收录使用文件预览后显式确认保存；原稿 PDF 账单、模拟忽略结果没有真实解析或候选持久模型，不显示虚假的完成状态。 | PDF 解析和逐条忽略未接入；不计作已通过。 |
| 账号图谱与密码库引用 | 图谱节点切换、打开关联资产、关联密码库条目 | 账号关系沿现有真实 Relation 记录导航；密码库只保存外部条目引用和保管位置，不接收密码或恢复码。 | 已有功能，项目／账号及引用操作沿用既有定向回归。 |
| 设置与助手授权 | 基础设置、授权入口、连接同步入口 | 设置页只展示已接通的本机状态；授权范围与访问记录由现有能力处理，官方云入口继续受阶段门禁约束。 | 已有功能；本轮不把原稿静态 toast 当作连接成功。 |
| 备份、导入和回收站 | 实际 `.ka1` 备份恢复、删除与恢复 | 走既有本机仓库的加密备份、附件恢复和墓碑恢复；关闭交接保留独立流程。 | 已有功能；旧矩阵不代表所有故障条件通过。 |

历史的 [UI 布局检查](evidence/2026-09-29/ui-restoration-checks.json) 只证明当时中英视口布局与部分点击；旧版 43 项不能覆盖此表新增的资料更新、关闭交接、账单、实物状态和维护计划。原稿中仅弹出提示、试用示例或标注“未连接”的控件不能当成正式应用的成功操作；本表按真实写入、回读或明确不可用状态判定。此前“域名成本无对应领域字段”的记录也已由项目域名模型与实际增改删验收取代。4180 同源旧 Chrome 标签页由监督在不清站点数据的情况下常规刷新两次后看到新版，项目详情真实流程亦已回读；此证据属于上一包验收，不能替代本轮构建和流程回归。新工作流移动首屏图：[中文 390](evidence/2026-09-29/project-workflow-mobile-zh-CN-390.png)、[英文 390](evidence/2026-09-29/project-workflow-mobile-en-390.png)；实物状态详情与弹窗图：[中文 390](evidence/2026-09-29/item-status-zh-390.png)、[英文 390](evidence/2026-09-29/item-status-dialog-en-390.png)。
