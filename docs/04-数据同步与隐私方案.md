# 04 数据、同步与隐私方案

## 数据模型

各实体拥有稳定随机id、workspaceId、schemaVersion、创建/修改时间与删除标记。时间用于展示，不能单独作为冲突胜负规则。

| 实体 | 主要内容 |
|---|---|
| assets | 类型、名称、分类、标签、扩展字段；类型细节按schema校验 |
| relations | from/to、关系类型、来源、核实时间；支持方向和反向查询 |
| projectProfiles | 网站短/长描述、联系方式、Logo、截图、外链资料映射 |
| submissions | 项目id、目标站规范标识、状态、目标URL、提交/核验时间、依据 |
| subscriptions | 金额最小货币单位、币种、周期、下次日期、试用/优惠、付款方式引用 |
| physicalItems/events | 购买/保修/位置、借还与维护事件；保留历史 |
| tasks | 到期时间、来源实体、状态、去重键、完成记录 |
| attachments | 归属id、MIME、大小、内容校验、对象引用、上传状态 |
| categories/preferences | 用户分类、排序、语言与展示偏好 |
| importBatches | 原始来源、映射、候选、用户确认与处理结果 |

金额不使用浮点累加。日期区分纯日期、带时区事件；多币种不直接相加。关系删除、附件引用和回收站须有修复/清理规则。

## 本地与云各存什么

- 本地RxDB保存可查询资产，二进制仓库存图片附件。本机数据默认依赖设备/浏览器保护，未实现全库静态加密前不得称“本地加密保险库”。
- 官方同步保存密文信封和同步元数据，R2保存加密文件；登录/计费信息另库。
- 搜索和图谱在本地计算。云端无法凭密文生成资产搜索或读取到期日期。
- 用户自备S3/WebDAV先用于加密备份；Google Drive等提供商逐个实现授权适配，不宣传一个URL支持所有云盘。

## 同步流程

1. 本地写入并立即更新UI；记录待同步操作。
2. 开启同步后，客户端加密内容，按批次push；携带期望服务端版本及操作id。
3. 服务端校验身份、workspace归属和旧版本，在数据库事务内写入并分配递增序号；重复操作幂等返回。
4. pull按服务端序号分页取变化，客户端解密后写本地；游标仅在批次落盘后推进。
5. 并发改同一字段显示差异；账号关联/删除等不采用静默最后写入覆盖。无冲突字段可合并但保留版本依据。
6. 图片先本地落盘，后台上传，核对后标记就绪；下载失败不使整条资产消失。

RxDB本身不保证跨集合事务。领域多记录变更使用操作日志和可恢复状态机；阶段0模拟中断证明恢复一致。删除保留tombstone，离线超保留期设备先全量重建，不能让旧设备复活已删除数据。附件垃圾清理由引用和保留期决定。

UI状态固定为“已保存在本机 / 待同步 / 同步中 / 已同步 / 需处理冲突 / 同步失败”；“已同步”必须同时有服务端确认和本地游标证据。

## 端到端加密门槛

官方同步上线前必须完成加密、设备加入、恢复、撤销与迁移测试；此前可以发布本地版，不上线未完成保护的个人云同步。

采用libsodium成熟实现作为候选：文档与附件使用认证加密；设计选XChaCha20-Poly1305，独立随机nonce，AAD绑定workspace/记录id/schema版本。大文件分块与清单一起认证，防止截断/重排。封装和密钥协议须专项审查，安装包版本与许可仍待锁定，不能因为采用算法就宣称产品已安全。

随机数据密钥由已授权设备保存，通过独立恢复密钥包装；新设备经已有设备或恢复凭据解锁。登录密码重置不等于数据解密恢复。设备撤销阻止未来访问，不能收回它已下载的明文；需要轮换后续密钥。服务端不保存解密密钥和恢复明文。MVP不做多人共享密钥。

阶段 3 已实现本机软件纵切：已有浏览器可生成 10 分钟加入凭据，另可生成独立恢复凭据；服务端按工作区保存不透明密钥包装，读取受账号成员权限、过期及撤销约束，新浏览器在本机解密并核对工作区与指纹，再手动使用现有密文同步。`.ka1` 仍只含记录与原图，不含工作区密钥。当前“撤销”仅停止此包装的后续领取；已领取密钥的设备撤销和后续密钥轮换尚未实现，不能据此声称完整设备管理或官方云同步已开放。实现及风险边界见 [ADR 0007](adr/0007-工作区密钥加入与独立恢复.md)。

服务端仍可观察账户、IP、时序、密文大小及不透明文档标识；不能宣传“完全无元数据”。客户端解锁后XSS仍可读取资料，需要CSP、依赖管控、不把外部HTML直接插入、缩短授权生命周期。

[libsodium认证加密文档](https://libsodium.gitbook.io/doc/secret-key_cryptography/aead/chacha20-poly1305/xchacha20-poly1305_construction)

## AI、MCP与后台通知

- 默认只读；范围细到选定资产/字段，界面显示将发给哪个模型的哪些资料。
- 写入先返回变更预览，确认后执行；删除、批量变更单独授权。工具请求幂等，日志不写敏感原文。
- BYOK、私有模型地址、远端MCP须连接测试；浏览器CORS/混合内容限制需提供可选自部署代理，不承诺任意地址直连。
- API密钥不进普通资产字段；服务端使用secret配置，客户端持久化方案需专门评估。
- 关闭App后的可靠到期通知需要后台运行服务；用户单独同意发送最少日期/通知资料，或使用自己信任的服务器。纯密文服务器不能自动分析资产。
- 服务端URL抓取阻止私网/元数据地址，校验重定向和DNS变化、限制体积/时间。云AI授权不等于网页提交授权。

## 备份与退出

版本化归档包含manifest、资产、关系、分类、历史、原图附件与校验。默认加密备份；丢失恢复密钥不可由客服解密。恢复先预检，展示重复和冲突，再进入可回滚导入；干净浏览器恢复后核对数量、图片、关系与金额。

同步不是备份，云盘不是数据库。取消付费后仍能本地读写和导出，云端保留期必须事先公开；删除账号包含云对象、备份保留说明与完成回执。
