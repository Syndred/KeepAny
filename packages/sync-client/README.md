# 自托管网页同步客户端

`SelfHostSyncClient` 是用户主动启用的浏览器客户端，只连接显式填写的自托管 Hono 服务。调用方提供 `LocalRepository`、服务地址、该服务的静态 Bearer 令牌、工作区 UUID 和 32 字节工作区密钥。令牌与密钥只在当前页面内存中使用；页面仅记住服务地址与工作区 ID。官方云入口仍关闭。

每条待推送记录先按服务地址、单账户主体 `self-host-owner`、工作区 UUID 建立隔离的持久快照和操作 ID，再发密文。服务确认后才保存版本基线并移除待推送项。断网、重开页面或令牌轮换后，原操作及密文保持不变，再次推送由服务端按操作 ID 去重。相同作用域首次连接时会固定密钥指纹与 epoch；错用另一把密钥会在网络请求前停止。

拉取时按单条游标处理。v2 信封将记录版本和外部变更元数据认证，服务分配的全局序号只负责游标。已确认操作的原样回显只推进游标，保留之后发生的本机编辑。其他变更经认证与格式校验后写入 RxDB；遇到两端修改则保留本机记录和拉取日志，由用户选“保留本机”或“保留服务器”，然后继续同步。墓碑与显式恢复沿用服务端版本合同。

当前没有密文图片传输和设备密钥配对。任何本机资产引用图片时，整次同步在发请求前停止，避免只传记录而丢失图片。工作区密钥必须由用户另行安全保存；误删密钥或清除浏览器存储无法由本客户端自动恢复。一个服务地址目前只支持服务端的单账户 `self-host-owner` 模式，多用户正式身份未接入。

针对性验证：`pnpm exec vitest run packages/local-db/src/scoped-sync.test.ts packages/sync-client/src/index.test.ts`。
